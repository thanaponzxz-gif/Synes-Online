# Synes Online: เอกสารออกแบบ (vertical slice 1)

## ตัวตนของโลก
**Synes** คือดินแดนที่แสงมีเสียง เรียกว่า "ลูเมน" (lumen) ไหลเป็นสายผ่านคริสตัลที่เรียกว่า *ซายน์* ซึ่งฮัมเป็นสี
ทุกสิ่งที่สำคัญจึงสื่อด้วย **สี + รูปทรง + เสียง** พร้อมกันเสมอ ทั้งวงเตือนการโจมตี ทางเดิน และของมีค่า
ธีมนี้ทำให้ระบบอ่านท่าศัตรูเป็นส่วนหนึ่งของโลก ไม่ใช่แค่ UI

- **ผู้เล่น:** Wayfarer ผู้ถือดาบ *Chime Blade* ซิลูเอ็ตที่จำได้คือผ้าพันคอสี teal
- **ภูมิภาคแรก:** ทุ่งน้ำค้างแสง (Dewlight Glade)
- **ศัตรู:** พัฟแคป (สัตว์เห็ดกระโดด), ธอร์นลิง (ก้อนหนามพุ่งชน) และบอส **ปริซึมแบ็ก** (ด้วงเต่าหินมอสที่หลังเป็นคริสตัล)
- **palette:** lumen #5CF2E6 · violet #A78BFA · blossom #FF9EC7 · gold #FFC857 · teal #2BB3A3
  ส่วนสีส้ม #FF7A1A และแดง #FF3355 **สงวนไว้ใช้กับวงเตือนเท่านั้น**

## วงจรเล่นหลัก
สำรวจ → อ่านท่าศัตรู → ต่อสู้หรือร่วมมือ → ได้รางวัล → พัฒนาตัวละคร → ไปพื้นที่ถัดไป
slice นี้มีครบตั้งแต่สำรวจไปจนได้รางวัล ส่วน "ร่วมมือ" กับ "พัฒนาตัวละคร" ยังเป็นงานรอบถัดไป (ดู HANDOFF)

## การบังคับบนมือถือ (แนวนอนก่อน)
| ปุ่ม | หน้าที่ | หมายเหตุการออกแบบ |
|---|---|---|
| ครึ่งจอซ้าย | จอยสติ๊กลอย (แตะที่ไหนก็ได้) | ไม่ต้องเล็งจุดเล็ก ๆ |
| ⚔ | ฟัน คอมโบ 3 จังหวะ (กดค้างได้) | auto-aim ศัตรูใกล้สุดในระยะ 4.2 m |
| ↯ | พุ่งหลบ 0.3 s และไม่โดนโจมตีระหว่างพุ่ง | cooldown 0.55 s ต้องสั้นกว่าเวลาเตือนที่สั้นที่สุด (มี test คุม) |
| ✧ | ระฆังสะท้อน: ทำดาเมจรอบตัวและขัดจังหวะท่าที่กำลังชาร์จ | cooldown 8 s |
| ✚ | ยา 2 ขวด | บ่อแสงเติมให้ |

**หลบเพอร์เฟกต์:** พุ่ง *ผ่าน* การโจมตีขณะอยู่ในวงพอดี จะทำให้ตีครั้งถัดไปแรงขึ้น ×1.5 และ cooldown สกิลลดลง 2 s
กลไกนี้ให้รางวัลกับการอ่านท่า ไม่ใช่การกดรัว

## ด่าน "ทุ่งน้ำค้างแสง" (เป้าหมาย 2–3 นาทีสำหรับผู้เล่นใหม่)
1. **ค่ายพัก (ปลอดภัย):** มีกองไฟ เต็นท์ ป้ายบอกทาง และคำแนะนำเรื่องการเดิน ทางเดินชี้ไปข้างหน้า (ทิศ −Z ที่อยู่ไกลจากกล้อง) จึงเห็นทางข้างหน้าตลอด
2. **เส้นทาง A:** พัฟแคป 2 ตัวที่ตีช้า (เตือน 1.2 s) ใช้สอนวงส้ม การหลบ และดาว ✦ ที่บอกว่าตีสวนได้
3. **ลานโล่ง:** ประตูคริสตัลปิด แล้วเจอพัฟแคป 3 ตัวพร้อมธอร์นลิง (แถบพุ่งชน) เพื่อสอนการใช้สกิลขัดจังหวะ
4. **เส้นทาง C + บ่อแสง:** ฟื้นพลัง เติมยา และเป็นจุดเกิดใหม่ก่อนบอส
5. **ลานบอส:** ประตูปิดด้านหลัง และมีเสาคริสตัล 4 ต้น
6. **ผลจบ:** แสดงอันดับ S/A/B/C, สถิติ, รางวัลที่ server ตรวจแล้ว, ปุ่ม "เล่นอีกครั้ง" และตัวอย่างพื้นที่ถัดไป

## บอส: ปริซึมแบ็ก (HP 1000)
| ท่า | วงเตือน | เวลาเตือน (P1 / P2) | วิธีรับมือ |
|---|---|---|---|
| กวาดเขา | พัดด้านหน้า 120° สีส้ม | 0.80 / 0.68 s | หลบไปด้านข้างหรือด้านหลังบอส |
| กระแทกปริซึม | วงรอบตัว r 4.6 สีแดง | 1.25 / 1.06 s | วิ่งออกนอกวง |
| พุ่งคริสตัล | แถบยาว 18 m สีแดง | 1.00 / 0.85 s | ยืนหน้าเสาแล้วหลบด้านข้าง บอสจะชนเสาและมึน 2.6 s (ช่วงตีสวน ดาเมจ ×1.5) |
| ฝนผลึก (เฉพาะ P2) | วงเล็ก 5 วงไล่ตาม | 1.0–1.64 / ×0.85 | เคลื่อนที่ต่อเนื่อง |

- **เฟส 2** เริ่มที่ HP 50% บอสคำราม ท่าเร็วขึ้น และเพิ่มฝนผลึก
- **เมื่อแพ้** หน้าจอจะบอกว่าแพ้ให้ใครด้วยท่าอะไร พร้อมเคล็ดลับของท่านั้นโดยเฉพาะ แล้วเกิดใหม่ที่บ่อแสงพร้อมบอส HP เต็ม
- **ความยุติธรรม (มี test คุม):** ทุกท่าเตือนอย่างน้อย 0.65 s ในทุกเฟส และ cooldown หลบสั้นกว่าเวลาเตือนที่สั้นที่สุด

## สิ่งที่ server ตัดสิน (ไม่เชื่อ client)
ผลแพ้ชนะ, เวลา, ดาเมจที่ได้รับ, จำนวนครั้งที่แพ้, การหลบเพอร์เฟกต์, อันดับ, ทอง/EXP และของดรอป
client ส่งได้อย่างเดียวคือ input log ส่วน server จะจำลองซ้ำเอง (ดู ADR-002)
