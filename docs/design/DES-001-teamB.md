ทำตาม DES-001 §4 ("ตีอัตโนมัติ") เท่านั้น **ไม่ทำฟาร์มออฟไลน์** (มีแค่แถวปิดใช้งาน "ฟาร์มออฟไลน์ · ยังไม่เปิด" ในแผง) ไม่แตะจังหวะโจมตี/คอมโบ และไม่แก้ตัวเลขใน `shared/data/tuning.ts` ไม่แตะ `src/render/view.ts`

### สิ่งที่ทำ
- **ตัวควบคุม Auto อยู่ใน sim** (`shared/sim/auto.ts`, เรียกจาก `World.step`) ทำงานจากสถานะโลกแล้วสร้าง `TickInput` ปกติ (เดิน + โจมตี + ปุ่มสกิล) ส่งเข้า `updatePlayer` เดิม จึงไม่มีทางลัดที่ผู้เล่นทำไม่ได้ ใช้แค่ `+ - * /` และ `sqrt` ไม่มี random/นาฬิกา/trig
- **ค่าตั้ง:** เปิด/ปิด, ชนิดเป้า (ทุกชนิด หรือเลือกชนิด), พื้นที่ (รอบจุดเดิม รัศมี 4–20 ม. ค่าเริ่ม 8 / ทั้งโถง), สวิตช์สกิล 1–3 (ปิดทั้งหมดตอนเปิดครั้งแรก), ทำงานต่อหลังคืนชีพ (ปิดเป็นค่าเริ่มต้น)
- **กติกา §4 ครบ:** บันทึกจุดยืนเป็นศูนย์กลางตอนเปิด · เลือกมอนมีชีวิตที่ตรงตัวกรอง อยู่ในพื้นที่ และเส้นตรงไปถึงได้บนพื้นเดินได้ · ใกล้สุดก่อน เท่ากันเอา id ต่ำสุด · รักษาเป้าจนตาย/หลุดพื้นที่/ไปไม่ถึง · ไม่มีเป้ากลับจุดศูนย์กลางแล้วรอ · ไม่เดินข้ามโซนหรือประตูปิด · 30 tick ไม่คืบหน้าเลิกเป้า · ชุดสกิล Chime (ขัดท่าที่กำลังเตรียม) → Crystal (≥2 ตัว) → Crescent (≥1 ตัว) → ตีปกติ เฉพาะช่องที่เปิดสวิตช์และพร้อม · หลบ/ยา/อัลติเป็นของผู้เล่น · คำสั่งมือชนะใน tick เดียวกัน และพัก Auto จนอินพุตมือหมดและท่าที่ผู้เล่นสั่งจบ · เข้าเขตลานบอสแล้วปิด ไม่เปิดคืนเอง · ตายแล้วล้างเป้า/คำสั่งค้าง (ถ้าเลือกทำงานต่อ จุดเกิดใหม่เป็นศูนย์กลางใหม่ และทำงานเฉพาะในพื้นที่ที่อนุญาต)
- **โซนของ "โถง"** เพิ่มใน `shared/data/level.ts` (`autoZones`): `path` = ค่าย+ทางเดิน, `clearing` = ลานกลาง, `exit` = ทางไปลานบอส ส่วน `arenaEntry` กับ `arena` ไม่อยู่ในโซนใด จึงเป็น "ลานบอส" ที่ปิด Auto
- **UI:** ปุ่ม AUTO (รูปสวิตช์ `ui_toggle_v01` + คำว่า เปิด/ปิด) กับปุ่มฟันเฟืองตั้งค่าแยกกัน วางมุมซ้ายล่างใต้จอย ตามภาพเป้าหมาย DES-003 (ปุ่ม AUTO 98×46, ฟันเฟือง 46×46 CSS px ทั้งคู่ ≥ 44 และขยายตาม `--s` บนจอใหญ่) แผงตั้งค่าใช้สกินกรอบเดียวกับเมนูหยุด (`ui_panel_v01`) จัดสองคอลัมน์ให้พอดี 844×390 ทุกปุ่ม ≥ 44 px ปุ่ม Auto ซ่อนเมื่ออยู่ในลานบอส และมีแถบข้อความ "เข้าลานบอส · ปิดตีอัตโนมัติแล้ว" เมื่อปิดเอง
