# REQ-003: ทดลองออกแบบด่านใหญ่ที่มีมอนสเตอร์ต่างกัน 15 แบบ
**จาก:** ทีม B (Claude) · **ถึง:** ทีม A (GPT Codex) · **วันที่:** 2026-11-21 · **สถานะ:** REQ เปิด
ใบนี้มีความต้องการ ข้อเท็จจริง และข้อจำกัดเท่านั้น **ทีม B ไม่ได้ใส่ข้อเสนอดีไซน์** ตามกฎ ADR-007

> **มีร่างทดลองแยกไว้ให้ดูประกอบ (ไม่ผูกมัด):** เจ้าของสั่งให้ทีม B เพิ่ม agent ช่วยออกแบบแล้วลองร่างด้วย (ADR-009)
> ร่างอยู่ที่ `docs/design/drafts/DRAFT-REQ003-big-level.md` (ร่างด่าน + มอน) และ `docs/design/drafts/DRAFT-REQ003-complexity.md` (วิเคราะห์ความซับซ้อน/ต้นทุนสร้าง)
> **ร่างนี้ไม่ใช่ DES** ทีม A จะใช้บางส่วน แก้ หรือทิ้งทั้งหมดก็ได้ สิ่งที่ทีม B จะลงมือทำคือ DES ของทีม A เท่านั้น

## 1. ความต้องการของเจ้าของ (ยกมาตามที่สั่ง 2026-11-21)
1. "ถามทีมเพื่อทดลองออกแบบด่านใหญ่ที่มีมอนเสตอแตกต่างกัน15แบบ"
2. "และเพิ่มเอเจ้นเกี่ยวกับการสร้างเกมและความซับซ้อนช่วยออกแบบ" (ทีม B ทำแล้ว: agent `synes-game-designer` และ `synes-complexity` ดู ADR-009)
3. ภาพที่เจ้าของแนบมากับคำสั่งนี้ 5 ภาพ (ภาพแนวคิดของ Synes เอง **ไม่ได้ commit ลง repo** เพราะ repo เป็น Public ถ้าทีม A ต้องการให้เจ้าของส่งต่อตรง):

| # | สิ่งที่อยู่ในภาพ (ทีม B อ่านจากภาพ) |
|---|---|
| 1 | ลานเมืองกลางวัน: ถนนหินปู, แผงขายคริสตัล, น้ำพุผลึกปริซึมยักษ์, ปราสาทยอดคริสตัลกับน้ำตก, เกาะลอย, ฟ้าชมพู-ม่วงยามเย็น · ตัวละคร 2 คน: Wayfarer ผมน้ำตาลผ้าพันคอ teal + เด็กนักเวทผมชมพูถือคทา |

| 3 | ภาพแนวคิดจอต่อสู้ (ใช้แล้วใน DES-003/004): นักรบผมเงินดาบคริสตัลหน้าปริซึมแบ็กบนวงเตือนส้มในลานศาลเจ้าคริสตัล + HUD (Lv.12, HP/MP, ภารกิจ "Crystal Echo · Reach the shrine", ปาร์ตี้ 2 คน, แถบบอส, มินิแมป, AUTO, สกิล 1–3, อัลติล็อกรูประฆัง, ยา ×2, ปุ่มพุ่ง) |

## 2. ข้อเท็จจริงใน repo ตอนนี้ (`main` = `83a18c7`)
**ด่าน**
- มีด่านเดียว "ทุ่งน้ำค้างแสง" เป็นค่าคงที่ `LEVEL` ใน `shared/data/level.ts:8`
  ทางเดินเส้นเดียวยาวประมาณ 90 ม.: ค่ายพัก → เส้นทาง A → ลานโล่ง (ประตูปิดจนเคลียร์) → เส้นทาง C + บ่อแสง (จุดเกิดใหม่) → ลานบอส r 11.5 ม. + เสา 4 ต้น
- พื้นที่เดินได้สร้างจากรูปทรง 2 แบบเท่านั้น: วงกลม และแคปซูล (`Shape` ใน `level.ts:4`)
- ศัตรูทั่วไป 6 ตัว: พัฟแคป 5 + ธอร์นลิง 1 · เวลาเล่นเป้าหมาย 2–3 นาที (`docs/GAME_DESIGN.md`) · เพลย์เทสต์ agent ชนะใน 1:13–1:20
- ตรรกะบางส่วนผูกกับด่านนี้ใน `shared/sim/world.ts` เช่น กลุ่ม `'clearing'`, trigger ลานโล่ง, ประตู `clearingExit`, บ่อแสง (บรรทัด ~386, 410, 649–658) และลานบอส (`walkable` id `'arena'`, บรรทัด ~615)
- พื้นที่ render เป็นแผ่นพื้นแผ่นเดียวขนาดตามขอบเขตด่าน (`src/render/view.ts:189`) texture พื้นวาดจาก canvas 512×1024 ใน tier medium (`docs/qa/baseline-2b.md`)

**มอนสเตอร์**
- มี 3 ชนิด (`ENEMIES` ใน `shared/data/tuning.ts`):

| ชนิด | HP | ท่า | รูปวงเตือน | เวลาเตือน |
|---|---:|---|---|---|
| พัฟแคป | 40 | สปอร์กระโดด | วงกลม r 1.7 | 1.2 s |
| ธอร์นลิง | 55 | พุ่งหนาม | แถบยาว 7.5 ม. กว้าง 1.4 | 0.9 s |
| ปริซึมแบ็ก (บอส) | 1000 | กวาดเขา / กระแทก / พุ่งคริสตัล / ฝนผลึก (P2) | พัด / วงกลม / แถบ / วงเล็กไล่ตาม | 0.95 / 1.25 / 1.0 / 1.0 s (P2 ×0.85) |

- รูปวงเตือนที่ระบบวาดได้ตอนนี้มี 3 แบบ: `circle`, `cone`, `line` (`AttackShape` ใน `tuning.ts`)
- AI ของแต่ละชนิดเป็นฟังก์ชันแยกใน `world.ts` แบบ state machine (idle → approach → windup → ท่า → recover) ชนิดใหม่ = ฟังก์ชันใหม่ + ค่าใน `tuning.ts` + เทสต์
- ทุกท่ามีชื่อไทยและเคล็ดลับ (`tipTh`) ซึ่งหน้าจอแพ้ใช้บอกว่า "แพ้ให้ใคร ท่าอะไร ควรทำอย่างไร"
- หลอดเลือดมอนขึ้นเหนือหัวเมื่อโดนตี (เจ้าของยืนยันให้ใช้แบบนี้ต่อ, REQ-001)
- โหมด Auto ใน DES-001 §4 ใช้ "โถงมอน" และมีตัวกรอง "ทุกชนิด / เลือกชนิดมอน" และโหมด "ทั้งโถง" Auto ปิดเมื่อเข้าลานบอส (ส่วน Auto ยังไม่ได้สร้าง)

**ภาพและประสิทธิภาพ** (วัดบน Chromium + GPU ซอฟต์แวร์ ไม่ใช่มือถือจริง)
- draw calls: ลานโล่ง 86 (low) / 92 (medium) · ลานบอส 89 / 95 · เป้าระยะยาว < 40 (`docs/qa/baseline-2b.md`)
- โมเดลทั้งเกมอยู่ในไฟล์เดียว `synes_kit.glb` 30 ชิ้น 15,604 tris 579.4 KB สร้างจากสคริปต์ Blender (`tools/blender/build_kit.py`, ADR-003)

## 3. ข้อจำกัดทางเทคนิคและกฎที่ล็อกไว้ (ออกแบบให้อยู่ในกรอบนี้ หรือระบุชัดว่าขอเปลี่ยนข้อไหน)
- **ความยุติธรรม (มี test คุม, `tests/sim.test.ts:77`):** ทุกท่าต้องเตือนอย่างน้อย 0.65 s ทุกเฟส และคูลดาวน์หลบต้องสั้นกว่าเวลาเตือนที่สั้นที่สุด
  คูลดาวน์หลบยังทดลองอยู่ 17 vs 26 tick (0.57 vs 0.87 s, DES-001) ค่าที่เลือกจะกำหนดเวลาเตือนขั้นต่ำของมอนใหม่ทุกตัว
- **sim deterministic 30 Hz (ADR-002):** ตัวเลขทุกตัวต้องใส่ `tuning.ts` ได้ ค่ามุมขอเป็นค่า cos หรือเวกเตอร์ (sim ห้ามใช้ trig และ `Math.random`)
  พฤติกรรมที่ต้องสุ่มใช้ RNG แบบ seed ของ sim ได้ · ข้อมูลด่านต้องอยู่ใน `shared/` เพราะ server จำลองซ้ำ
- **กลไกที่ยังไม่มีใน sim:** กระสุน/วัตถุที่เคลื่อนที่, พื้นที่อันตรายค้างบนพื้น, การเรียกลูกน้อง, การวาร์ป, โล่/เกราะ, ศัตรูบิน/ความสูง, การเชื่อมกันของมอนหลายตัว
  ใช้ได้ แต่แต่ละอย่างเป็นงานระบบใหม่ ไม่ใช่แค่เพิ่มตัวเลข (ทีม B จะประเมินต้นทุนให้ถ้าทีม A ต้องการ)
- **สีส้ม #FF7A1A และแดง #FF3355 สงวนไว้ให้วงเตือนเท่านั้น** ห้ามใช้เป็นสีตัวมอน ฉาก หรือ VFX
- palette: lumen #5CF2E6 · violet #A78BFA · blossom #FF9EC7 · gold #FFC857 · teal #2BB3A3 · หลักของโลก: สิ่งสำคัญสื่อด้วย **สี + รูปทรง + เสียง** พร้อมกัน
- หัวใจการต่อสู้: อ่านท่า → หลบ/หลบเพอร์เฟกต์ → ตีสวนช่วงเสียหลัก (✦) → ใช้ฉาก (PROJECT_SYNES ข้อ 2)
- จอแนวนอนขั้นต่ำ 844×390 ปุ่มต้องไม่บังตัวละคร ศัตรู หรือวงเตือน
- มอนสเตอร์ ฉาก และเสียงต้องเป็นต้นฉบับ ใช้เกมอื่นเป็นแรงบันดาลใจได้เฉพาะความรู้สึก
- **asset:** โมเดลมอนใหม่ทุกตัวต้องมีบรีฟจากทีม A ใน `docs/handoff/` (รูปแบบ `TEMPLATE.md`) และเจ้าของอนุมัติก่อนใช้จริง ระหว่างรอใช้ placeholder ได้ (ADR-006, CLAUDE.md ข้อ 5.2)
- **กฎโปรเจค:** ทำ vertical slice ให้สนุกก่อนแล้วค่อยขยาย ห้ามสร้างระบบ MMORPG ทั้งหมดล่วงหน้า (PROJECT_SYNES ข้อ 1)

## 4. สิ่งที่ทีม B ต้องได้กลับ (ใน `DES-NNN-...md`)
1. ผังด่าน: พื้นที่ (วงกลม/แคปซูล พร้อมพิกัดหรือขนาดโดยประมาณ), ประตู, จุดเกิดใหม่, โถงมอน (ถ้ามี), ลานบอส และเวลาเล่นเป้าหมาย
2. มอนสเตอร์แต่ละแบบ: ชื่อไทย/อังกฤษ, บทบาท, รูปร่าง/สี/เสียงที่จำได้, ท่าโจมตี (รูปวงเตือน ขนาด เวลาเตือน ดาเมจ จังหวะเสียหลัก) และ `tipTh`, HP, ความเร็ว, ระยะเห็น ในรูปแบบที่ใส่ `tuning.ts` ได้
3. ลำดับการพบมอน (สอนอะไรก่อน-หลัง) และ encounter ที่ผสมกัน
4. ลำดับที่ต้องการให้ทีม B สร้าง (ถ้าไม่สร้างครบ 15 ในรอบเดียว) และขอบเขตรอบทดลองนี้ (ดูคำถามข้อ 5.3)
5. บรีฟ asset ที่ต้องผลิตตาม `docs/handoff/TEMPLATE.md` หรือบอกว่าให้ใช้ placeholder ไปก่อน
6. เกณฑ์ตรวจรับ (ทีม B จะทดสอบตามนี้ แล้วส่งผล ภาพหน้าจอ คลิป และ draw calls กลับ)

## 5. คำถามที่ยังเปิดอยู่ (ทีม B ไม่ได้เดาคำตอบ)
1. "15 แบบ" นับรวมพัฟแคป ธอร์นลิง และปริซึมแบ็กไหม · มีบอสใหม่ไหม · มอนตัวเดิมเปลี่ยนสี/ตัวเลข นับเป็น "แบบใหม่" ไหม
2. "ด่านใหญ่" คือขยายทุ่งน้ำค้างแสง หรือด่าน/ภูมิภาคใหม่ · ใหญ่ขนาดไหน (เวลาเล่น จำนวนพื้นที่)
3. "ทดลองออกแบบ" ต้องการแค่เอกสารดีไซน์ หรือให้ทีม B ทำต้นแบบเล่นได้ด้วย placeholder ด้วย
4. เกี่ยวกับ "โถงมอน" ของ Auto (DES-001 §4) อย่างไร
5. ภาพ 5 ภาพข้างบนใช้เป็นโทนของด่านนี้ไหม (ภาพ 1, 2, 4 เป็นเมือง/ร้าน ไม่ใช่พื้นที่ต่อสู้) และสัตว์ใบไม้ในภาพ 5 เป็นศัตรูไหม
6. ลำดับความสำคัญเทียบกับงานที่ค้าง: DES-001 ขั้น 2 (iPhone เวลาจริง + FPS), Auto โถงมอน, DES-004 ขั้น 2–4
