## 2. ทิศทางภาพ

ใช้แนวทาง **"low-poly สว่างนุ่ม + แสงเรืองจากผลึก"** เพราะภาพแบบ painterly ทั้งจอเหมือนภาพอ้างอิงทำไม่ได้ในเกมเว็บจริง ส่วนที่เลียนแบบได้คือ ค่า value สี บรรยากาศ และ silhouette

- **ไล่ value 3 ชั้น:**
  - ฉากหลังไกล: ฟ้าม่วงหม่น สว่างและ contrast ต่ำ
  - ฉากกลาง: ผลึกและศาล สว่างที่สุดในฉาก
  - ลาน: หินโทนกลาง
  - ตัวละครแยกจากพื้นด้วย rim light
- **palette:** ใช้สีเดิมทั้งหมด ได้แก่ lumen #5CF2E6, violet #A78BFA, gold #FFC857, stone #B9B4C7, blossom #FF9EC7 และใช้ cloth_teal #2BB3A3 กับผ้าพันคอ ซึ่งเป็นสัญลักษณ์ของ Wayfarer และต้องคงไว้แม้ภาพอ้างอิงจะไม่มี
- **ห้ามใช้ #FF7A1A และ #FF3355 ในฉากหรือแสงไฟ** แสงอุ่นกลางลานในภาพอ้างอิงให้ทำด้วย gold ที่อ่อนลง (≤ #FFE0A0) เพื่อให้วงเตือนยังเป็นสีส้ม/แดงที่สดที่สุดบนจอ
- **วงเตือน:** คง hex เดิม พื้นที่ อัตราการเติมสีตามเวลา และลำดับการวาดทับฉากตามเดิม ส่วนการแก้ shader ให้ทำตามข้อกำหนดใน DES-003

## 3. ลำดับผลิต

**ขั้น 1: แสงและบรรยากาศ** ทำใน Three.js ทั้งหมด ราคาถูกที่สุดและเปลี่ยนภาพได้มากที่สุด
- ปรับ hemisphere light เป็นฟ้าม่วงด้านบนและเขียวหม่นด้านล่าง ใช้ sun สีครีมจากด้านหลังซ้ายบนเพื่อให้เกิด rim บนตัวละคร
- ปรับ fog เป็นสีลาเวนเดอร์ (~#8E8FC8) และใกล้ขึ้น เพื่อดันฉากหลังให้ถอยไปไกล
- ทำ bloom ปลอมด้วย sprite แบบ additive ทรงวงรีหลังผลึกใหญ่ (ใช้ texture radial 64 px ใบเดียว) แทน post-processing
- UnrealBloomPass เป็นเป้าทดลองบน tier high เท่านั้น
- เพิ่มลำแสง (god rays) เป็น plane แบบ additive 2–3 แผ่น โดยทุก tier ต้องปิดได้

**ขั้น 2: ลานหิน น้ำตก และผลึก** ทำใน Three.js ร่วมกับ texture จาก canvas
- **พื้น:** เปลี่ยน canvas ใน `arena.ts` จากอิฐเรียงแถวเป็นแผ่นหินรูปทรงไม่สม่ำเสมอแบบ Voronoi
  - ร่องบางลงและเป็นสีเขียวมอส
  - กลางลานสว่างขึ้นเป็นโทน #A9A6BC
  - คงขนาด texture ตาม `groundRes` ของแต่ละ tier
- **หญ้าและดอกม่วงตามขอบลาน:** ใช้ instanced card ทำงานตาม `decoDensity` และต้องอยู่นอกพื้นที่เล่นเท่านั้น
- **น้ำตก 2 สาย:** ใช้ plane ที่เลื่อน UV บน texture แถบน้ำ 64×256 พร้อมละอองที่ฐาน
- **ผลึกใหญ่ (Blender):** สร้าง `crystal_spire` สูง 6–9 m ปลายแตกเป็นเหลี่ยม แทนก้อน icosahedron
- **ศาล:** สร้าง `ruin_arch_shrine` เป็นซุ้มโค้ง มีวงแหวนทอง ผลึกลอยกลางวง และบันได
- **ตำแหน่งศาล:** ย้ายไปชิดซ้ายหรือขวาของแกนกล้อง เพื่อไม่ให้บอสยืนบัง

**ขั้น 3: Prismback** ทำใน Blender ภายใต้ข้อกำหนดของ `build_kit.py`
- **ลำตัวและเกราะ:**
  - เปลี่ยนสีลำตัวจากม่วงดำเป็น stone #B9B4C7
  - แผ่นเกราะ 6–8 ชิ้น มีขอบ gold
  - ใส่รอยแตกเรืองสี lumen บนขาและข้างลำตัวเป็น emissive strip
- **ผลึกบนหลัง:** ลดจำนวนลงเหลือ 9–12 ชิ้น แต่ใหญ่ขึ้น 1.5–2 เท่า ให้ยอดกลางสูงสุดเป็นรูปปิรามิด
  - สีไล่จาก lumen ที่โคนถึง violet ที่ปลาย ทำด้วย vertex color หรือแยก material 2 ชุด
- **หัว:** หัวใหญ่ขึ้นและมีหงอนผลึก ดวงตาเป็นจุด lumen ที่อ่านได้จากกล้องเกม
- **ข้อกำหนดที่ต้องคง:** ชื่อ node `prismback_*` ทั้ง 4, ขนาด 3×5 m, หันหน้าไป +Z และจุดหมุนเดิม

**ขั้น 4: ฮีโร่** ทำใน Blender
- **ผม:** เปลี่ยนจากทรงกลมเป็นผมเงินแหลม 7–9 ปอย ให้เห็น silhouette ปอยผมจากด้านหลัง
- **ชุด:** เสื้อคลุมครีมขาว ขอบ gold ที่ไหล่และเข็มขัด ผ้าคลุม violet ปลายแยกเป็น 2 แฉก และคงผ้าพันคอ teal
- **ดาบ:** ใบดาบเป็นผลึก lumen แบบ emissive มีโกร่งทอง
- **ข้อกำหนดที่ต้องคง:** `hero_body`, `hero_head`, `hero_sword`, ความสูง 1.5 m, origin ของดาบที่ด้ามจับ และสัดส่วน chibi (หัว ~40%)

**ขั้น 5: เอฟเฟกต์** ทำใน Three.js
- ประกายผลึกลอยรอบลาน ใช้ point sprite ตามค่า `particles` ของแต่ละ tier
- วงแสง teal ใต้ฮีโร่ทำให้บางลงเป็นโทน lumen
- เมื่อดาบโดนผลึก ให้มีสะเก็ดเหลี่ยมสีฟ้า-ม่วง
- ห้ามใช้สีอุ่นในเอฟเฟกต์ทุกชนิด

**ขั้น 6: HUD portrait และไอคอน** ภาพต้นแบบผลิตด้วย GPT Image ตามสายงาน pipeline
- **ไฟล์:**
  - `ui_portrait_hero_v01.png` ขนาด 256² พื้นโปร่ง ครอปเฉพาะหน้า ใช้สีผมและชุดชุดเดียวกับโมเดลในขั้น 4
  - `ui_skill_icons_v01` เป็นไอคอนแบบภาพวาดชุดเดิมที่บรีฟรออนุมัติอยู่
- **ปรับ HUD (CSS):**
  - ชื่อบอสเป็นภาษาไทย ตัวอักษรสีครีม ขอบทอง และเงาม่วง
  - บนจอ 844 ตัวอักษรต้องสูงไม่ต่ำกว่า 14 px
  - ปุ่มล็อกยังคงคำว่า "ล็อก"

## 6. เกณฑ์เทียบเฟรม

ถ่ายภาพที่ tick เดียวกันกับภาพชุดเดิม ได้แก่ ช็อตเปิดสู้, วงเตือนวงกลม, พัด และเส้นพุ่ง ทั้งที่ 1672×941 และ 844×390 แล้วตรวจตามตารางนี้

| ข้อ | เกณฑ์ผ่าน |
|---|---|
| ความชัดของวงเตือน | สีส้มและแดงต้องเป็นสีอุ่นที่สดที่สุดบนจอ ขอบวงต้องเห็นชัดทั้งบนพื้นหินและบนตัวบอส |
| silhouette | เห็นปอยผมฮีโร่และผ้าคลุม 2 แฉก บอสอ่านเป็นเกราะหินที่มีผลึกบนหลัง และเห็นหัวบอสได้ |
| การไล่ value | ผลึกและศาลสว่างกว่าพื้น ส่วนฉากหลังจางกว่าฉากกลาง ให้ทดสอบด้วยการแปลงภาพเป็นขาวดำ |
| การบัง | ปุ่มและจอยต้องไม่บังบอสหรือวงเตือน ผลึกริมลานต้องไม่บังฮีโร่ระหว่างสู้ด้านข้าง |
| HUD ไทยบนจอ 844 | อ่านชื่อบอส ตัวเลข HP และคำว่า "ล็อก" ได้ |
| perf | วัดค่าจาก `renderer.info` ทุก tier ให้อยู่ในงบตามตารางหัวข้อ 4 แล้ววัด FPS ระหว่าง phase 2 บนเครื่องจริง |

**สถานะการทดสอบ:**
- **Android:** ยังไม่ได้ทดสอบ
- **iPhone:** ยังไม่ได้ทดสอบ แบบเวลาจริงยังไม่มีตัวเลข FPS
- **PC:** มีเพียงภาพนิ่งจาก DES-003 ยังไม่มีผลจากงานตามบรีฟนี้

### §8 stage1 arena (ทีม B, 2026-11-21, branch `exp/stage1-arena`, รายงาน `docs/qa/arena-v01/README.md`)
- **ทำแล้วเป็นต้นแบบ ยังไม่เป็นค่าเริ่มต้น** เปิดดูได้ด้วย `?arena=A` และ `?arena=B` ถ้าไม่ใส่ param ภาพจะเหมือนเดิมทุกพิกเซล (0 px ต่างใน 18 เฟรม)
- **งานขั้น 2 ส่วน Three.js:** พื้นหิน Voronoi ร่องเขียวมอสบางใน canvas เดิม (`groundRes` เดิม) · หญ้าและดอกม่วงแบบ instanced ตามขอบนอกวงเล่น (`decoDensity`) · น้ำตก 2 สายเลื่อน UV (64×256) พร้อมละออง · ย้ายศาลไปขวาแกนกล้อง (ศาลไม่ใช่วัตถุชนใน sim)
- **DES-006 §3:** ผลึกซากเรืองแสงตามสีของตัวเอง หน้าผาไกลใช้สีหมอก และเสาซากใช้หินกลาง
- **งบ:** +2 draw calls ทุกเฟรม และ texture +0.125 MB ทั้ง A และ B ส่วน crystal_spire / ruin_arch_shrine (Blender) ยังไม่ทำ (เป็นของอีกสาย)
- **แกน A/B คือความสว่างของพื้น**
  - **A** คงพื้นมืดระดับเดิม (บนจอ ~0.25) ความต่างความสว่างของขอบเตือนไม่ลดลงในเฟรมใดเลย (WCAG 2.49–3.46 vs เดิม 2.45–3.11) ผลึกซ้าย 0.53 / เสา 0.47 สว่างกว่าพื้น 0.25
  - **B** ใช้ #A9A6BC ตาม §3 (บนจอ ~0.47) ลานสว่างขึ้น (ทั้งจอ 0.43 vs 0.31) แต่ขอบเตือนเหลือ WCAG 1.25–1.60 ขอบแดงมืดกว่าพื้น และศาลไม่สว่างกว่าพื้น
- **ทีม B เสนอ A** และรอทีม A ตัดสินว่า "#A9A6BC" กับ "ขอบเตือน hex ล็อก" ควรยึดข้อไหน (คำถาม 1–6 ใน README)
- ค่า 0.31 vs 0.34 ด้านบนวัดที่กล้องสูงแบบเก่าบน tier high ส่วนที่กล้องต่ำปัจจุบัน ผลึกซากซ้ายได้ 0.39 และเสาผลึกซ้ายได้ 0.47 เทียบพื้น 0.30 จึงผ่านอยู่แล้วก่อนแก้ แต่ระยะห่างน้อย
