# DES-002 · ผลการทำ HUD skin (ทีม B)

branch `lane/hud-skin` (แตกจาก `main` @ `e9a50de`) · ยังไม่ push ยังไม่ merge · ส่งให้ทีม A ตรวจ
ใช้ PNG ใน `public/assets/ui/` ตามเดิม **ไม่ย้อมสี ไม่ใช้ CSS gradient เลียนกรอบ** ตัวเลข/คูลดาวน์/จำนวนยายังเป็น DOM ที่ `src/ui/hud.ts` ขับ ไม่แตะ `shared/`, ปุ่มตำแหน่ง/ขนาดตาม DES-001 §3 ไม่เปลี่ยน, ไม่มีสี #FF7A1A / #FF3355 ใน UI
