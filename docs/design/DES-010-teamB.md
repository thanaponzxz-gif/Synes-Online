**ข้อสังเกตจากภาพ**

- **F-2 เส้นโค้ง sweep:** หนา 0.06 ม. opacity 0.45 อยู่ 4 tick ที่ 844×390 มองแทบไม่เห็น (ภาพ `04-sweep-impact`) แหวน slam (0.10 ม.) มองเห็น
- **F-3 สีแดงของพื้นที่เตือน** วาดทับปูทั้งตัวตาม ADR-005 เหมือนบอสเดิม ตัวปูจึงถูกย้อมแดง/ส้มขณะอยู่ในวง (ไม่ได้เปลี่ยนสีใน asset)

## 3. อ่านท่าออกไหมในเกม (PM ถาม · เป็นข้อมูลให้ทีม A ไม่ได้แก้คลิปเอง)

ดูจากภาพนิ่งที่กล้องเกมจริง 844×390 (ปูกว้างราว 110 px) ซึ่งจับตรง state ของ sim ยังไม่ได้ดูเป็นภาพเคลื่อนไหวบนเครื่องจริง

| ท่า | อ่านออกไหม | สิ่งที่เห็น |
|---|---|---|
| idle / walk | แยกจากกันยาก | ลำตัวและก้ามอยู่ตำแหน่งเกือบเดิม ต่างกันที่ขาซึ่งเล็กมากที่ระยะนี้ |
| sweep ช่วงง้าง (tick ~17) | **อ่านยาก** | ก้ามกางออกเล็กน้อย เงาร่างแทบเหมือน walk |
| sweep จังหวะ 30 | พออ่านได้ | ก้ามข้างหนึ่งกวาดข้ามหน้าลำตัว |
| slam ช่วงง้าง (tick ~17) | **อ่านยาก** | ก้ามยกขึ้นน้อย เงาร่างใกล้ idle มาก |
| slam จังหวะ 30 | พออ่านได้ | ก้ามสองข้างกดลงหน้าลำตัว |
| charge_windup / charge | อ่านยาก | ตัวอยู่ไกลกล้องตอนพุ่ง (กล้องถอย) เห็นจากแถบเตือนและฝุ่นเป็นหลัก |
| shard_cast | **ไม่ทราบ** | ทุกภาพที่จับได้ ปูอยู่ระหว่างกล้องกับผู้เล่นจึงถูก fade |
| roar (intro) | อ่านยาก | ที่ tick 15 ของคลิป ท่าใกล้ idle |
| stunned | **ไม่ทราบ** (ภาพที่จับได้ถูก fade) | ✦ สามดวงชัด |
| down | พออ่านได้ (ภาพเดียว มุมข้าง) | ลำตัวลดต่ำลง เห็นได้ 0.45 วินาทีก่อนหายตามระบบเดิม |

สรุปตามจริง: ตรงกับที่ PM เห็นในภาพรวมท่าของ Codex **ในเกม ช่วงง้างของ sweep กับ slam ต่างจาก idle/walk น้อย** ผู้เล่นรู้ว่าเป็นท่าไหนจากวงเตือน ไม่ใช่จากท่าของปู ส่วนจังหวะ impact (marker 30) และ down ต่างพอให้เห็น ทีม B ไม่ได้แก้คลิปและไม่ได้ขยายท่าด้วยโค้ด

## 5. ยังไม่ทราบ / ยังไม่ได้ทำ

- **Android / iPhone: ยังไม่ได้ทดสอบ** · FPS บนเครื่องจริง, frame time เทียบก่อน/หลังบนอุปกรณ์เป้าหมาย: ไม่ทราบ
- ยังไม่ได้ทดสอบ: ฝนห้าวงพร้อมอัลติเซย์ริน (§5.3 ข้อ 5), ภาพเคลื่อนไหวต่อเนื่องที่ความเร็วจริง (QA จับภาพด้วยนาฬิกาช้า ×0.2 เพราะ software rendering), เงา (Medium/Low ปิด shadow map อยู่แล้ว ปูใช้เงากลมเดิมใต้ตัว)
- ทีม B ไม่ได้วัดเอง: loop ต้น–ท้าย, hold 30→31, stretch, เท้าจม (§5.3 ข้อ 3) และรอยต่อ skin แบบเป็นระบบ (ข้อ 2)
- การหยุดนาฬิกาภาพเมื่อ pause/hidden (§3.3 ข้อ 8): ภาพผูกกับ tick ของ sim ซึ่งหยุดเมื่อ pause จึงไม่ไล่เล่นเวลาที่หายไป แต่ไม่ได้เขียน QA เฉพาะข้อนี้
- ที่มา/สิทธิ์ของปูยัง UNKNOWN ตามแบบ · ไฟล์ยังเป็น REVIEW (ป้ายบนจอบอกอยู่) · ปูอยู่บน dev server เครื่องนี้เท่านั้น ไม่ได้อยู่ในบิลด์ใด
- พบระหว่างทำ (ไม่ได้แก้ อยู่นอกงานนี้): ด่านเองทิ้ง geometry +13 / texture +1 ต่อการเริ่มรอบใหม่ทั้งกับบอสเดิมและปู
