## 2. ข้อเท็จจริงใน repo และบนเครื่องเจ้าของ (ทีม B ตรวจ 2026-11-28)

  3. Codex ทำ rig และ weight (45 bones)

  6. ทีม B เขียน ruleset `ninja-roam-1`, AnimationMixer, solver ผ้า, VFX และ HUD
