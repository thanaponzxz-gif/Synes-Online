# DES-002 · HUD skin จากภาพต้นแบบที่เจ้าของเลือก (ทีม A)
> บันทึกตามข้อความที่เจ้าของส่งต่อจาก Codex (2026-11-20) **ไม่แก้ไขเนื้อหา** · ภาพต้นแบบ: `assets/source/ui_hud_sheet_v01.webp`

## ข้อความต้นฉบับ
> รับงาน HUD จาก Codex ให้ใช้ภาพที่เจ้าของเลือกเป็นต้นแบบหลัก ประกอบด้วย PNG โปร่งใสทับฉาก Three.js เริ่มชุดปุ่มต่อสู้ก่อน แล้วทำจอย แถบเลือด และเมนูตามลำดับ แยกตัวเลข คูลดาวน์ และจำนวนยาเป็นข้อมูลจากเกม รักษาทรงกรอบทองและผิวแก้วม่วง ตรวจขอบโปร่งใสก่อนใช้ ส่งภาพเทียบที่ 844×390 พร้อมคลิปกดจริงให้ Codex ตรวจ งานนี้ใช้ HTML/CSS กับภาพ PNG ได้ ส่วน Blender ใช้เมื่อมีงานโมเดลหรือเรนเดอร์ 3D ที่จำเป็น

## ลำดับงาน
1. ชุดปุ่มต่อสู้ → 2. จอย → 3. แถบเลือด → 4. เมนู
