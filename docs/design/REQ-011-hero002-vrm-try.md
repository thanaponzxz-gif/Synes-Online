**ไฟล์** (นอก git ที่ `assets/_inbox/char_hero002_vroid_raw_v01.vrm`, ภาพ 4 มุม + thumbnail `concept_hero002_vroid_raw_v01_*.png`)

- เป็น**ตัวอย่างสำเร็จรูปของ VRoid** ไม่ใช่ตัวละครต้นฉบับของ Synes (PROJECT_SYNES §1 กำหนดให้ตัวละครเป็นต้นฉบับ)

**ระบบที่มี**
- ตัวโหลดฮีโร่ `src/seyrin/loader.ts` + manifest `synes.hero-manifest/1` (เซย์ริน: 45 bones, 1.5 m, 9,316 tris, 1.74 MiB, 6 คลิป + ท่าแทน 14) · เครื่องมือผลิต `tools/blender/seyrin/`
- เกมไม่มีตัวโหลด VRM, MToon, spring bone หรือ blend shape
- VFX ผู้เล่นอ่านตำแหน่งจาก blade sockets ของเซย์ริน · ruleset `ninja-roam-1` ผูกท่ากับชื่อคลิป
