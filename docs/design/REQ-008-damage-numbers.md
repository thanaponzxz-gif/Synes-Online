# REQ-008: เลขดาเมจแบบใหม่
**จาก:** ทีม B (Claude PM) · **ถึง:** ทีม A (GPT Codex) และเจ้าของ · **วันที่:** 2026-11-27 · **สถานะ:** REQ เปิด
ใบนี้มีความต้องการ ข้อเท็จจริง ข้อจำกัด และคำถามเท่านั้น **ไม่มีข้อเสนอดีไซน์**

## 1. ความต้องการของเจ้าของ (2026-11-27)
- เจ้าของส่งภาพอ้างอิงพร้อมข้อความ "และอยากให้เลขดาเมจแบบนี้"
- ภาพอ้างอิงเป็นภาพจากเกมอื่น **ใช้เป็นแรงบันดาลใจด้านความรู้สึกเท่านั้น** (PROJECT_SYNES ข้อ 1) และไม่เก็บใน repo สาธารณะ ทีม B ส่งภาพให้ทีม A ทางช่องส่วนตัว
- สิ่งที่เห็นในภาพ (ทีม B บรรยาย): ตัวเลขหนาใหญ่ทรงการ์ตูน ไล่สีในตัวเลข (ชมพูบานเย็น → ส้ม/เหลือง) ขอบหนาสองชั้น (ขาวด้านใน เข้มด้านนอก) มีเงาเหลื่อมให้ดูนูน และมีประกายดาวสีขาวเหลืองด้านหลังตัวเลขบางตัว

## 2. ข้อเท็จจริงใน repo (`lane/free-roam`)
- เลขดาเมจเป็น DOM ซ้อนบน canvas 3D: `src/ui/hud.ts` `floater()` สร้าง `div` ต่อหนึ่งเลข ลบทิ้งหลัง 0.9 วิ · สไตล์ใน `src/style.css` `.floater` และ `@keyframes float` (โผล่ ขยาย 1.1 แล้วลอยขึ้นจาง) · ตำแหน่งสุ่มเหลื่อม ±18 px แนวนอน ±7 px แนวตั้ง
- ชนิดที่มีตอนนี้: `dmg` ผู้เล่นตี (ขาว 20 px), `crit` คริติคอล (gold 26 px), `hurt` ผู้เล่นโดน (ชมพูอ่อน ขอบแดงเข้ม 24 px), `heal` ยา (เขียว), `perfect` PERFECT!/เสียหลัก (lumen), `early` หลบเร็วไป (blossom บนแคปซูลเข้ม) และข้อความไทย "ขัดจังหวะ!" ใช้ชนิด `crit`
- ทุกชนิดใช้ขอบ `-webkit-text-stroke` 4 px สีเข้ม + เงา · ฟอนต์ระบบ (`system-ui`, Noto Sans Thai) ไม่ฝังฟอนต์ (`docs/ASSETS.md`)
- ตัวเลขดาเมจมาจาก event `hit` ของ sim (`e.amount`, `e.crit`, `e.byPlayer`) ภาพไม่มีผลต่อการคำนวณ (ADR-002)

## 3. ข้อจำกัดทางเทคนิค
- **สีแดง #FF3355 และส้ม #FF7A1A สงวนไว้ให้วงเตือนการโจมตีเท่านั้น** (palette อื่น: lumen #5CF2E6, violet #A78BFA, blossom #FF9EC7, gold #FFC857, teal #2BB3A3)
- DOM อยู่เหนือ canvas ทั้งหมด จึง **บังวงเตือนได้** ถ้าตัวเลขใหญ่หรืออยู่นาน · กฎเดิม: ปุ่ม/UI ต้องไม่บังตัวละคร ศัตรู หรือวงเตือน (PROJECT_SYNES ข้อ 1, ADR-005)
- จอเป้าหมายคือมือถือแนวนอน (ทดสอบที่ 844×390) · คอมโบ + สกิลวงกว้างทำให้มีหลายเลขพร้อมกัน
- วิธีวาดที่ทำได้ (ทีม A เลือก): CSS อย่างเดียว (ไล่สีในตัวอักษร + ขอบหลายชั้นทำได้ แต่ต้องซ้อนหลายชั้น), ชุดภาพตัวเลข 0–9 (sprite) ที่ทำเป็น asset, หรือวาดบน canvas · ฟอนต์ใหม่ต้องมี license ที่ใช้ได้ (เช่น OFL) ลงทะเบียน `docs/ASSETS.md` และเพิ่มน้ำหนักโหลด · ข้อความภาษาไทยต้องอ่านได้ด้วย
- ถ้าเป็นงานภาพ (sprite/ประกาย) ต้องผ่าน `docs/ASSET_PIPELINE.md` และเจ้าของอนุมัติก่อนใช้จริง · ถ้างานไหนต้องเจนภาพ/โมเดล ให้แจ้งเจ้าของ (เว็บ Hunyuan3D สำหรับ 3D ตาม ADR-014)
- ตัวละครหลักกำลังเปลี่ยนเป็นนินจา (ADR-014, DES-007) VFX ของสกิลใหม่อยู่ใน DES-007
