## 3. เรื่องที่ทีม B แก้ได้เองโดยไม่ต้องรอใบนี้ (ไม่เปลี่ยนสิ่งที่ผู้เล่นเห็น) · รอเจ้าของจัดรอบ
SEC-1 (ตรวจ path ของ static server ด้วย `startsWith(ROOT)` ไม่มีตัวคั่น: `/..%2fdist-spike/index.html` ออกไปโฟลเดอร์ข้างเคียงที่ชื่อขึ้นต้นด้วย `dist` ได้ · PM ยืนยันด้วย node แล้ว · ไต่ลึกกว่านั้นไม่ได้), SEC-2/3 (map `runs`/`hits` ไม่มี TTL, rate limit ใช้ IP ของ socket), SEC-5 (ส่ง `e.message` กลับ client), PERF-1…4 (DOM/การสร้าง object ทุกเฟรม) · ต้องมีเทสต์ยืนยันว่าภาพและผลเท่าเดิม
