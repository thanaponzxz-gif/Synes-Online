# fx_boss_defeat_v01
**สถานะ:** DRAFT · **ผู้ผลิต:** Blender (เศษคริสตัล 3–5 ชิ้นจาก `build_kit.py`) + โค้ดเอฟเฟกต์ใน `src/render/fx.ts` · **ผู้ตรวจ:** Claude (PM) → เจ้าของอนุมัติ
**ใช้ที่ไหนในเกม:** ตอนปริซึมแบ็กพ่าย (ก่อนหน้าผลจบ) ความยาว 1.2–1.8 วินาที
**แทน placeholder:** ตอนนี้บอส "แตกเป็นประกาย" (อนุภาคทั่วไป) แล้วกล้องซูมเข้า

## Art Direction (ห้ามเปลี่ยน)
- ลูเมนคือแสงที่มีเสียง ตอนบอสล้ม คริสตัลบนหลังควร "ดังกังวาน" แล้วแตกเป็นเศษแสง lumen/violet ลอยขึ้น และตัวหินทรุดลงนิ่ง (ไม่โหด ไม่มีเลือด)
- palette: lumen #5CF2E6 · violet #A78BFA · gold #FFC857 · **ห้ามส้ม #FF7A1A และแดง #FF3355**

## สเปก
- โมเดล: เศษคริสตัล 3–5 แบบใน kit (`fx_crystal_shard_a..e`) ไม่เกิน 60 tris ต่อชิ้น
- โค้ด: บอสทรุดตัว 0.4 s → คริสตัลกระพริบ 2 ครั้ง → แตกเป็นเศษ 12–20 ชิ้น ลอยขึ้นแล้วจาง ใช้ instanced mesh (+1 draw call ระหว่างเล่นฉากนี้เท่านั้น)
- ใช้ได้ทุก tier โดย tier low ลดจำนวนเศษลงครึ่ง
- ไม่บังหน้าผลจบ และไม่ยืดเวลาก่อนขึ้นผลจบเกิน 2 s
