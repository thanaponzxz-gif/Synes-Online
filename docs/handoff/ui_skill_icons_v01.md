## สเปก
- PNG RGBA พื้นโปร่ง หนึ่งไฟล์ต่อไอคอน 128×128 px
- ยึด silhouette ตามตารางใน DES-001 §2:
  - Chime Burst = ระฆังกับวงแหวน
  - Crescent Cut = คมเสี้ยวจันทร์เอียงขวา
  - Crystal Break = ผลึกสามแฉกจากรอยแตก
  - อัลติ = ระฆังซ้อน + ล็อก บนพื้น slate
- ไม่มีตัวอักษร เงาเบา และเว้นช่องไฟรอบขอบ
- ห้ามใช้ส้ม #FF7A1A และแดง #FF3355
