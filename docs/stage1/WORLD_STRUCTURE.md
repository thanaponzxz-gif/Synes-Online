
- **โทนที่ไม่ใช้กับโซนต่อสู้ [เสนอ]:** `dusk` ฟ้าส้มอมม่วง (`tones.ts:27`) และ `prism` อิ่มสีสูงจนแย่งวงเตือน (`tones.ts:24`) เพราะชนกับสีสงวน · `blossom`/`amber` เป็นโทนเมือง ซึ่งไม่อยู่ในแผนนี้ · เจ้าของยังไม่ได้เลือกโทน (`PROJECT_SYNES.md` §5)
- **ขนาด ≤ 116 m [เสนอ]:** ทุกโซนอยู่ใน plane 68×116 เดิม งบ texture ของ ground canvas จึงเท่าเดิม (`baseline-2b.md` §3)
- **จำนวนศัตรู [เสนอ]:** ไม่เกิน 10 ตัวธรรมดา + บอส 1 ต่อโซน และตื่นพร้อมกันไม่เกิน 6 ตัว (ลานกลาง Z1 ตอนนี้ 4 ตัว, `level.ts:27-30`)

### 1.4 การเชื่อมต่อและ gating [เสนอ]
- **1 โซน = 1 รัน** (seed + input log + server replay ชุดเดียว ตาม ADR-002) ไม่มี open world หรือการ stream ฉาก ข้ามโซนผ่านหน้าผลจบเหมือนตอนนี้
- **ปลดล็อกโซนถัดไป:** server ต้องยืนยันว่าชนะบอสของโซนก่อน (client ห้ามตัดสินเอง) ส่วนช่วงเดโมที่ไม่มีบัญชีจะเก็บที่ไหน ดู S3
- **ภายในโซน:** ประตูลานล็อกเปิดเมื่อกลุ่มตายหมด และประตูลานบอสปิดหลังผู้เล่น ใช้กลไกเดิม (`world.ts:663-677`)
- **ฮับ:** ยังไม่มีเมืองกลาง ใช้ค่ายพักต้นโซนแทน เมืองรอระบบออนไลน์ (`PROJECT_SYNES.md` §6 ข้อ 7)
- **กลับไปเล่นโซนที่ผ่านแล้ว:** ทำได้ (เล่นซ้ำหรือ Auto) จากรายการโซนแบบง่าย ไม่ใช่แผนที่โลก
