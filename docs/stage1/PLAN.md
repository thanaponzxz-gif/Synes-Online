## ขอบเขตกับกฎ ADR-007 (ทีม A ออกแบบก่อน)
- เจ้าของสั่งให้ทีม B ตั้งบทบาท Art Direction / Technical Art / Level Design / Gameplay / QA แล้วสร้างตัวเลือก A/B และเลือกเองบน **branch งาน**
- ทุกตัวเลือกที่เปลี่ยนภาพหรือความรู้สึกยังเป็น **ต้นแบบรอทีม A และเจ้าของตรวจ** ก่อนเข้า `main` (เข้า `main` ต้องให้เจ้าของสั่ง)
- งานศิลป์กราฟิกใช้ Opus (CLAUDE.md ข้อ 0) · โค้ดที่ไม่เปลี่ยนภาพ / QA ใช้ Sonnet ได้
- asset ชั่วคราวจาก Blender สคริปต์เป็น placeholder ยังไม่ APPROVED (ADR-006) ต้องลงทะเบียนใน `docs/ASSETS.md`
- ตัวเลขสมดุล (ความเร็วตี ฯลฯ) ไม่แตะ รอทีม A (REQ-003)

## บทบาท (ห้ามออกแบบเรื่องเดียวกันซ้ำ)
| บทบาท | ตัดสินเรื่อง | ไม่ตัดสิน |
|---|---|---|
| Art Direction | ภาพเป้าหมายของแต่ละจุด (value, สี, silhouette, จุดนำสายตา) | วิธีทำ, ตัวเลขเกม |
| Technical Art | วิธีทำ + งบ perf ของแต่ละตัวเลือก | ภาพเป้าหมาย |
| Level Design | เส้นทาง จังหวะ จุดนำสายตา ตำแหน่งวัตถุที่กระทบการเดิน | สี/วัสดุ |
| Gameplay | ความชัดของการต่อสู้ วงเตือน การบัง ความสนุก | ภาพตกแต่ง |
| QA | ภาพก่อน-หลัง, regression, FPS (สัมพัทธ์), draw calls, lifecycle | การเลือกดีไซน์ |
| PM | ลำดับรอบ, เลือกตัวเลือกจากผล QA ตามเกณฑ์ข้างล่าง, merge ลง `stage1/polish` | — |

## ลำดับรอบ (รอบละ 1–2 จุด)
0. baseline จากมุมกล้องจริง + perf-field
1. ฉากเปิด (ค่ายพัก → เส้นทาง A)
2. ลานบอส (DES-004 ขั้น 2)
3. ตัวละคร (ฮีโร่, ปริซึมแบ็ก — DES-004 ขั้น 3–4)
4. VFX (DES-004 ขั้น 5)
- ด่านใหญ่ + มอนสเตอร์ 15 แบบ: **เอกสารโครงสร้างเท่านั้น** ทดลองจริงแค่ 1 พื้นที่ (ทุ่งน้ำค้างแสง) กับมอนสเตอร์ 3 แบบที่มีอยู่ (พัฟแคป, ธอร์นลิง, ปริซึมแบ็ก) ห้ามขยายจนด่านแรกผ่านเกณฑ์

## เกณฑ์ "ด่านแรกผ่าน" (ใช้เลือกตัวเลือกด้วย)
1. **ความชัด (สำคัญสุด):** วงเตือนส้ม/แดงเป็นสีอุ่นที่สดที่สุดบนจอ, ไม่มี #FF7A1A/#FF3355 ในฉาก, ปุ่ม/ผลึกไม่บังวงเตือนหรือฮีโร่ (ADR-005, DES-004 §6)
2. **ภาพ:** value 3 ชั้น (ไกลจาง / กลางสว่าง / ลานกลาง) ตรวจด้วยภาพขาวดำ, silhouette ฮีโร่และบอสอ่านได้ที่ 844×390
3. **perf (Chromium headless 844×390):** ทุ่ง ≤ 75 draw calls, ลานบอส low/medium ไม่เกินค่า baseline +10, GLB ≤ 700 KB, texture เพิ่ม ≤ +0.5 MB
4. **regression:** `npm test`, typecheck, build, lifecycle 20/20 ผ่าน, ไม่มี page error
5. **ไม่เปลี่ยนตัวเลขเกม** (`shared/**` ไม่แตะ ยกเว้นทีม A สั่ง)
- มือถือจริง: **ยังไม่ได้ทดสอบ** จนกว่าเจ้าของจะเล่นบนเครื่อง (ห้ามอ้างว่าผ่าน)
