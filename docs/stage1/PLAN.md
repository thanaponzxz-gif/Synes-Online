## บทบาท (ห้ามออกแบบเรื่องเดียวกันซ้ำ)
| บทบาท | ตัดสินเรื่อง | ไม่ตัดสิน |
|---|---|---|
| Art Direction | ภาพเป้าหมายของแต่ละจุด (value, สี, silhouette, จุดนำสายตา) | วิธีทำ, ตัวเลขเกม |

| Level Design | เส้นทาง จังหวะ จุดนำสายตา ตำแหน่งวัตถุที่กระทบการเดิน | สี/วัสดุ |
| Gameplay | ความชัดของการต่อสู้ วงเตือน การบัง ความสนุก | ภาพตกแต่ง |
| QA | ภาพก่อน-หลัง, regression, FPS (สัมพัทธ์), draw calls, lifecycle | การเลือกดีไซน์ |

## ลำดับรอบ (รอบละ 1–2 จุด) — ปรับตาม DES-006 ของทีม A (`90d3b4d`, 2026-11-21)
DES-006 ตอบ REQ-003, กล้องต่ำ, ผังปุ่ม/วงเตือน DES-003, DES-004 และ Q1–Q73 แล้ว จึงทำตามดีไซน์ทีม A ก่อน แล้วค่อยทำตัวเลือกภาพ
0. baseline จากมุมกล้องจริง (`qa/stage1-baseline`) + ลด draw calls ภาพไม่เปลี่ยน (`lane/perf-field`)
1. **จังหวะตี A/B/C** เป็น variant + `rulesetVersion` (DES-006 §1, `lane/combo`) → คลิปให้เจ้าของเลือก · **วงเตือนแยกสีจาก fog/แสง** (DES-006 §2)
2. **กล้อง:** ถอย/ยกชั่วคราวเมื่อศัตรูหรือขอบวงหลุดจอ (DES-006 §1) · **HUD:** ยา ≥44, อัลติ 46, ชื่อบอส ≥14 px, HP ≥12 px, Q41/Q44/Q72 และ Q17/Q29–Q34
3. **ฉากเปิด:** ผลึกซ้ายสว่างกว่าพื้น + ลำดับ value ที่กล้องต่ำ (DES-006 §3, DES-004 ขั้น 1) · **ลานบอส** DES-004 ขั้น 2 (ตัวเลือก A/B)
4. **ตัวละคร** DES-004 ขั้น 3–4 + ผ้าพันคอ teal ต้องอ่านได้จากมุมเล่น (DES-006 §3)
5. **VFX** DES-004 ขั้น 5 + Q26 (prep cue ของ Chime)
- ด่านใหญ่ + มอนสเตอร์ 15 แบบ: **เอกสารโครงสร้างเท่านั้น** (`docs/stage1/WORLD_STRUCTURE.md`) ทดลองจริงแค่ 1 พื้นที่ (ทุ่งน้ำค้างแสง) กับมอนสเตอร์ 3 แบบที่มีอยู่ ห้ามขยายจนด่านแรกผ่านเกณฑ์

## เกณฑ์ "ด่านแรกผ่าน" (ใช้เลือกตัวเลือกด้วย)
1. **ความชัด (สำคัญสุด):** วงเตือนส้ม/แดงเป็นสีอุ่นที่สดที่สุดบนจอ, ไม่มี #FF7A1A/#FF3355 ในฉาก, ปุ่ม/ผลึกไม่บังวงเตือนหรือฮีโร่ (ADR-005, DES-004 §6)
2. **ภาพ:** value 3 ชั้น (ไกลจาง / กลางสว่าง / ลานกลาง) ตรวจด้วยภาพขาวดำ, silhouette ฮีโร่และบอสอ่านได้ที่ 844×390
3. **perf (Chromium headless 844×390):** ทุ่งมุมต่ำ Low ≤ 80 / Medium ≤ 100 draw calls (งบทีม A, DES-006 §1; `lane/perf-field` ตั้งเป้าเข้มกว่าที่ ≤ 75), ลานบอส low/medium ไม่เกินค่า baseline +10, GLB ≤ 700 KB, texture เพิ่ม ≤ +0.5 MB
4. **regression:** `npm test`, typecheck, build, lifecycle 20/20 ผ่าน, ไม่มี page error
5. **ไม่เปลี่ยนตัวเลขเกม** (`shared/**` ไม่แตะ ยกเว้นทีม A สั่ง)
- มือถือจริง: **ยังไม่ได้ทดสอบ** จนกว่าเจ้าของจะเล่นบนเครื่อง (ห้ามอ้างว่าผ่าน)
