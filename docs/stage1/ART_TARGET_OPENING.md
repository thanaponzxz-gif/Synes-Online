> **เป้าหมายจาก Art Direction (ทีม B) ตามคำสั่งเจ้าของ — รอทีม A ตรวจ** · ยังไม่ใช่ดีไซน์ที่อนุมัติ (ADR-007) · เข้า `main` ได้หลังทีม A + เจ้าของตรวจเท่านั้น (`docs/stage1/PLAN.md:8`)

- **ผู้จัดทำ:** Claude Code Opus 5.5 · ทีม B · บทบาท Art Direction · branch `docs/art-target-opening` (ฐาน `stage1/polish` `ceef2f1`)

- **ฐานอ้างอิง:** DES-004 §2 (low-poly สว่างนุ่ม + ผลึกเรือง, value 3 ชั้น, แสงอุ่น ≤ #FFE0A0) · DES-006 §3 (ผลึกสว่างกว่าพื้น, ลำดับภาพที่กล้องต่ำ, ผ้า teal) · `GAME_DESIGN.md` ด่านข้อ 1–2 · r0 baseline · `docs/qa/chars-v01/` (ฮีโร่แบบ A)
