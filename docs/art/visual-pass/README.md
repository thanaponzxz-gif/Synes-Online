# Visual pass PoC (branch `art/visual-pass-poc`, ยังไม่ merge)

ต้นแบบปรับภาพแบบเบาสำหรับมือถือ ใช้ `?style=0` เพื่อดูแบบเดิม และ `?style=1` (ค่าเริ่มต้นใน branch นี้) เพื่อดูแบบใหม่
ภาพเทียบ: `trail-*.png`, `combat-*.png`, `clearing-*.png` (844×390 @2x, กล้องเกมจริง, วางฉากเหมือนกันทุกจุด)

| เทคนิค | ผลที่เห็น | ต้นทุน | ข้อเสนอ |
|---|---|---|---|
| Toon ramp 3 ขั้น | แสงเงาเป็นขั้น อ่านทรงได้ดีขึ้นเล็กน้อย | ใกล้เคียง Lambert | เก็บไว้ |
| ลงสีพื้น (หย่อมสี, เส้นหญ้า, กรวดบนทาง) | พื้นมีมิติ ไม่เรียบแบน | 0 draw call (วาดลง texture ตอนโหลด) | เก็บไว้ |
| เงาใต้ต้นไม้/หิน (วาดลง texture) | ฉากดูยึดติดพื้น | 0 draw call | เก็บไว้ |
| หญ้าเป็นกอ (instanced) | ขอบทางมีชีวิต | +1 draw call, ~+11k tris (medium) | เก็บไว้ ปิดใน tier low |
| ละอองแสง | บรรยากาศ "Synes" | +1 draw call | เก็บไว้ |
| Vignette (CSS) | ดึงสายตาเข้ากลางจอ | ไม่ใช้ GPU pass | เก็บไว้ |
| Rim light ตัวละคร | ตัวละครเด่นจากพื้น แต่บอสซีดในโทนมืด | ใกล้ 0 | ปรับความแรงตามโทน |
| เส้นขอบแบบ inverted hull | ตัวละครเด่นขึ้น แต่**ขอบแตกเป็นหยัก**เพราะ normal แบบ flat | **+~45 draw calls** (1 ต่อชิ้นส่วน) | ทำใหม่ใน Blender: อบ hull ลง mesh ด้วย vertex color และ smoothed normals จะไม่เพิ่ม draw call |

รวมทั้งหมด: draw calls 89→137, tris 49k→65k, FPS เทียบลดลง 3–9% (Chromium + SwiftShader, เครื่องรันงานอื่นพร้อมกัน จึงใช้ดูทิศทางเท่านั้น)
