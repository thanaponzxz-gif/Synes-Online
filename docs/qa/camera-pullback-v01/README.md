## วิธีทำ (render อย่างเดียว ไม่แตะ sim)
- ทุกเฟรมหา pull ที่น้อยที่สุด (0–1.2, ทีละ 0.1) ที่ทำให้จุดเหล่านี้อยู่ในพื้นที่ปลอดภัยของจอ (NDC x ±0.94, บน 0.94, ล่าง −0.86 เผื่อแถวปุ่ม):
  ขอบวงเตือน (วงกลม 16 จุด / พัด: ยอด+โค้ง+ขอบ / แถบ: 4 มุม โดยปลายแถบพุ่งนับไม่เกิน max(6, ระยะเลยผู้เล่น+4) m), ผู้เล่น, บอสเมื่อเริ่มสู้, ศัตรูที่ไม่ได้ยืนเฉยในระยะ 10 m
- pull ขยายระยะกล้องจากเป้าตามแนวมุมเดิม (offset × (1+pull)) จึงไม่หมุนและทิศควบคุมไม่เปลี่ยน · แนวตั้งไม่ใช้ pull
- เข้าเร็ว (10/s) → ค้าง 0.35–0.7 s → คืนช้า (0.9/s) · `?nopull` ปิดการถอย (ใช้เป็นภาพ "ก่อน" ในบิลด์เดียวกัน)

- **C1** ให้กล้องถอยล่วงหน้าก่อนวงเตือนเกิดไหม (เช่นตอนบอส/ธอร์นลิงเข้าท่าเตรียม) ตอนนี้ tick แรกของการเตือนยังตัดขอบ
