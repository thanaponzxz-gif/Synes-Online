## คำแนะนำ "ลากนิ้ว…" ค้างในลานบอส (ข้อสังเกต R0)
ตรวจแบบเวลาจริง (ไม่ freeze, บอตเล่น, `hint-realtime-before.json`):
- **เริ่มจากค่ายตามปกติ:** คำแนะนำเดินขึ้นตอนเริ่มและถูกคำแนะนำหลบแทรกที่ ~3.5 s (เห็นครั้งสุดท้าย sim 2.5 s) บอสเริ่มที่ 23.2 s คำแนะนำที่ขึ้นในลานบอสคือ บ่อแสง และ เสา (ตรงสถานการณ์) **ไม่มี "ลากนิ้ว…" ในลานบอส**
- **`?start=boss` (ทางลัด QA ที่เกิดหน้าลานบอส):** บอสเริ่มที่ 3.0 s และ "ลากนิ้ว…" ยังอยู่ถึง ~4.8 s เพราะคำแนะนำนี้มีอายุ 7 s ตั้งแต่เริ่มรอบ
- สรุป: **เป็น artefact ของภาพ QA** (ทางลัด start=boss + sim หยุดเวลา ภาพถูกถ่ายภายใน 7 s แรก) ไม่ใช่บั๊กของการเล่นจริงตาม ADR-005 จึงไม่ได้แก้
- หลังแก้ (`hint-realtime-after.json`, เริ่มจากค่าย): ลำดับคำแนะนำเหมือนเดิมทุกอัน + คำแนะนำปุ่มจาง (Q32) ขึ้นที่ 6.4 s ตอนวงพัฟแคปอยู่ใต้ปุ่มจริง แล้วหลีกให้ "✦ ตีสวน" ที่ 7.9 s
  (คำแนะนำปุ่มจางเป็นระดับรอง: ไม่แย่งช่องจากคำแนะนำอื่นที่พร้อม และถูกแทนได้เมื่ออ่านไปแล้ว 1.5 s เหมือนกฎคำแนะนำด่วน; รอบแรกที่ลองแบบไม่มีระดับรองมันดัน "✦ ตีสวน" หลุดช่วงในลาน)

## ยังไม่ตรวจ
Android / iPhone จริง (การกดด้วยนิ้ว, safe area จริง, ความอ่านง่ายกลางแดด, Q31 "ทดสอบมือถือกลางวง") · ความรู้สึกของการสั่นปุ่ม · ป้ายสถานะเครือข่ายยาว "ออนไลน์ (สัญญาณหลุด รอส่งผล)" ที่ 844 อาจชิดแถบบอส (ไม่ได้วัด)
