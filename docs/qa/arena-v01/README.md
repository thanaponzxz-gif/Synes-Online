## 7. ข้อเสนอ: เลือก **A** (เทียบเกณฑ์ใน `docs/stage1/PLAN.md`)
1. **ความชัด (สำคัญที่สุด):** A ไม่ลดความต่างความสว่างของขอบเตือนในเฟรมใดเลย และเพิ่มขึ้นเหนือพื้น ΔE00 ≤ 3.8 ขอบเป็นสีอุ่นที่สดที่สุดใน 3D ครบ 16/16 · B ผ่านเรื่องสี (ΔE ดีกว่าด้วย) แต่ความต่างความสว่างลดลง 40–50% และขอบแดงกลับเป็นสีมืดกว่าพื้น จึงขัดกับ "ไม่ลดความต่างของขอบเตือน" ในงานนี้และ ADR-005
2. **ภาพ:** ทั้งสองแบบได้ value 3 ชั้น (ฉากกลางสว่างสุด ฉากหลังจางและ contrast ต่ำ) และผลึกซ้ายสว่างกว่าพื้น · A มีระยะห่างมากกว่า (+0.26 เทียบ +0.08) · B ใกล้ภาพอ้างอิงมากกว่า (ลานสว่าง บอสสีเข้มตัดกับพื้น) แต่ศาลไม่ผ่าน "สว่างกว่าพื้น" · **ข้อด้อยของ A:** ลานโดยรวมยังมืดเท่าเดิม (0.31) และพื้นเป็นผิวใหญ่ที่มืดที่สุดในจอ
3. **perf:** เท่ากันทั้งสองแบบ (+2 calls, +0.125 MB)
4. **regression:** ผ่านทั้งสองแบบ และ default ไม่เปลี่ยน
- **ความเสี่ยงที่ทราบ:** ขั้น 3 (Prismback เปลี่ยนเป็น stone #B9B4C7) จะทำให้บอสสว่างขึ้น บนพื้นมืดของ A บอสจะเด่นขึ้น บนพื้นสว่างของ B บอสจะกลืนกับพื้น (ยังไม่ได้ทดสอบ)

## 8. คำถามถึงทีม A
1. **DES-004 §3 (กลางลาน #A9A6BC) ขัดกับ DES-006 §2 (ขอบเตือน hex ล็อก):** ใต้แสงลาน หิน #A9A6BC ออกจอสว่างเท่าขอบแดงเกือบพอดี (WCAG 1.25) ควรยึดข้อไหน? (A ยึดขอบเตือน, B ยึด #A9A6BC) ถ้ายึด A ลานจะสว่างขึ้นได้จากฉากกลาง/ฉากหลังเท่านั้น
2. **การยกค่าหน้าผาและเสาซาก** (สีหมอก, หินกลาง) อยู่นอกรายการขั้น 2 แต่ทำเพื่อลำดับ value ที่กล้องต่ำ (DES-006 §3) รับได้ไหม?
3. **ตำแหน่งศาล** (ขวา x +5.2 หัน −0.3 rad และถอดเสาหลังขวา 2 ต้น) รับได้ไหม? ที่ 844 ขอบบนของวงแหวนถูกแถบ HP บอสบัง ควรลดความสูงวงแหวน (เกี่ยวกับ `ruin_arch_shrine` ที่ทำใน Blender) หรือปรับ HUD?
4. **"ผลึกซ้าย" ที่ใช้เป็นเกณฑ์:** ที่กล้องต่ำ ผลึกที่เห็นชัดคือเสาผลึกของ sim (ซึ่งผ่านอยู่แล้ว 0.47 vs 0.30) ไม่ใช่กลุ่มผลึกซากที่ใช้วัดค่า 0.31 ควรใช้ชิ้นไหนเป็นเกณฑ์ หรือใช้ทั้งสองชิ้น?
5. ถ้าเลือก B: เพิ่ม emissive ของเสาผลึก sim ×1.8 รับได้ไหม? (เปลี่ยนการอ่านวัตถุ gameplay) และศาลที่ยังไม่ผ่าน "สว่างกว่าพื้น" จะให้ทำอย่างไร?
6. ความหนาแน่นของหญ้าและดอกม่วงตามร่องและตามขอบเหมาะไหม? (ดอกใช้ violet ไม่ใช้ blossom ชมพู เพราะชมพูนับเป็นสีอุ่นในเกณฑ์วงเตือน)
