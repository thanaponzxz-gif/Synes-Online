## 8. ข้อเสนอ (Technical Art)
- **ข้อเท็จจริง:** ทั้ง A และ B ผ่าน O1–O9 ที่ medium และผ่านทุกข้อที่ low ยกเว้น O6 (กรอบไม่มีต้นไม้ เหมือน current) ด้วยต้นทุนเท่ากัน (+2 calls, 0 texture) · ข้อ 5 (dither) และข้อ 6 (เต็นท์) ยังไม่ผ่านทั้งคู่
- **ข้อเสนอ: B เป็นตัวหลัก ถ้าทีม A ตอบ AQ1/AQ3 ว่าได้** เหตุผล: ภาพขาวดำมีลำดับ value ชัดกว่า (ทางไม่ใช่มวลสว่างสุดอีกต่อไป ผลึก p90 สูงกว่าทาง +0.26 เทียบ A +0.18), ค่าเฉลี่ยเฟรม 0.55 ทำให้เข้าลานบอส (0.32) นุ่มกว่า, ส้มบนพื้นหินเทาแยกด้วย hue ได้ดีกว่าส้มบนทางเบจ · ข้อควรระวังของ B: ขอบวงต่างจากทางในขาวดำเหลือ 0.13 (A 0.21) และโทน Z1 ขยับไปทางลานบอส
- **ถ้าต้องคง `dewlight` (AQ3 = ไม่):** ใช้ A ซึ่งผ่านเท่ากันและเสี่ยงน้อยกว่าเรื่องวงเตือน แต่ฉากยังสว่างทั้งจอ ลำดับภาพพึ่งจุดเรือง 2 จุด (ผลึก + ซุ้ม)
- ทางเลือกกลางที่ทำได้ทันทีถ้าทีม A ขอ: ใช้ผลึก/ซุ้ม/rim/โคมของ A กับทางหินเทาของ B โดยไม่เปลี่ยนฟ้า (ยังไม่ได้วัด)
- รุ่นถัดไป: วัดใหม่หลัง Level Design ตอบ AQ4 (ตำแหน่ง/ขนาดผลึกนำทาง) และหลังตัดสินข้อ 5 · ควรใช้ **Opus** ตรวจผล/ปรับภาพ, **Sonnet** รัน QA ซ้ำได้
