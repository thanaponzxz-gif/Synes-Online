# Stage 1 รอบ 0: baseline จากกล้องเกมจริง (ทุ่งน้ำค้างแสง)

บันทึกโดย QA ก่อนเริ่มรอบปรับภาพ ข้อมูลทั้งหมดเป็นข้อเท็จจริงที่วัดได้ ไม่มีข้อเสนอดีไซน์
build: `origin/stage1/polish` (main + `docs/stage1/PLAN.md`) · seed 1 · Chromium headless + SwiftShader

**ข้อจำกัด:** SwiftShader (GPU ซอฟต์แวร์) ไม่ใช่เครื่องจริง · FPS เป็นค่าสัมพัทธ์เท่านั้น · draw calls/tris ใช้เทียบก่อน-หลังได้ · **Android / iPhone ยังไม่ได้ทดสอบ**

## วิธีรันซ้ำ (ทุกรอบใช้คำสั่งเดียวกัน แล้วเทียบ)
```
npm run build
node tools/qa/stage1-shots.mjs docs/qa/stage1-v01/<รอบ>/shots --tag <รอบ>   # ~2.5 นาที, 50 ภาพ + report.json
  [--only opening,vfx]  [--jpeg]  [--base http://host:port]  (ไม่ใส่ --base = เสิร์ฟ dist/ ในตัว)
npm run server &                                   # :8080
node tools/qa/stage1-clip.mjs <out>.webm           # ~5 นาที
node tools/qa/bench.mjs http://localhost:8080 > bench.txt
```
- URL ทุกฉาก: `/?offline&seed=1&q=<low|medium>&autostart&qafreeze[&start=boss]` เดิน sim ด้วย `__synesQA.stepTicks` เท่านั้น ย้ายผู้เล่นด้วยการเขียน `world.player` (เหมือน atmos-shots/vfx-calls)
- ภาพ 844×390 dpr 1 (chars ใช้ dpr 2 แล้วครอป) · 1672×941 เฉพาะ opening, boss-open, boss-circle/fan/dash
- PNG รวม 27.8 MB เกินเพดาน 15 MB สคริปต์จึงแปลงเป็น JPEG (ffmpeg `-q:v 3`) อัตโนมัติ เหลือ 7.4 MB · ไฟล์ `*-gray.jpg` คือภาพขาวดำ (luma Rec.709) เฉพาะ opening และ boss-open
- **ความ deterministic:** รันซ้ำ 2 ครั้ง tick / draw calls / tris ตรงกันทุกภาพ · พิกเซลต่างเล็กน้อยในฉากที่มีอนุภาคหรือ CSS fade (ค่าต่างเฉลี่ยจาก 0.001 ถึง 0.6 จาก 255) จึงเทียบด้วยตาหรือเกณฑ์ ไม่ใช้ hash

## รายการสิ่งที่ผู้เล่นเห็น (ข้อเท็จจริงจากภาพ medium 844×390; low ต่างเฉพาะรายละเอียดที่ระบุ)
**opening**
- ฮีโร่อยู่กลางล่าง หันหลังให้กล้อง วงฟ้าอมเขียวรอบเท้าเด่น หัวเป็นทรงกลมสีเทาเงินอ่านเป็นหมวกเกราะ ผ้าคลุมม่วงยื่นออกด้านซ้าย
- เต็นท์อยู่ซ้ายของฮีโร่ กองไฟหินอยู่ขวาล่างใกล้ปุ่มสกิล ปุ่ม 1 บังกองไฟบางส่วน
- ทางดินเป็นแถบสีเบจสว่างพุ่งไปไกลสุดเฟรม มีโคมไฟทองและป้ายไม้ข้างทาง puffcap 2 ตัวบนทางเห็นเป็นจุดชมพูเล็กกลางภาพ
- ซุ้มหินที่ปลายทางจางลงเป็นสีฟ้าเทาตามระยะ (ชั้นไกลจางกว่าชั้นกลาง)
- กล่องคำแนะนำ (ลากนิ้วเพื่อเดิน) กินพื้นที่ซ้ายบนราว 230×45 px และทับต้นไม้ ต้นสนซ้ายและขวามีลายตาข่าย (dither) เห็นได้ในจุดที่โปร่งแสง
- ขาวดำ: ทางดินเป็นพื้นที่สว่างสุด (p95 = 223) ต้นไม้มืดกว่าทางชัดเจน ค่าเฉลี่ย 0.64
- หลังเดิน 2 วิ: puffcap ใหญ่ขึ้นเป็น 2 ตัวชัด ผลึกฟ้า-ม่วงโผล่ขวาของโคมไฟ

**path-A**
- วงเตือนส้มอ่อน (เนื้อวงโปร่ง ขอบส้ม) ใหญ่ล้อมฮีโร่และ puffcap ที่อยู่ติดฮีโร่ ครอบจนถึงขอบล่างของเฟรม
- ปุ่มสกิล 1 จางเป็นสีเทาโปร่งเพราะวงเตือนอยู่ใต้ปุ่ม ปุ่ม 2 และ 3 ยังทึบ
- ผลึกขวามือสีฟ้า-ม่วงสว่างกว่าพื้นทางที่อยู่รอบ ๆ

**plaza**
- เห็น puffcap 3 ตัว ธอร์นลิง 1 ตัว (เขียวเข้ม) แถบพุ่งสีส้มแคบทอดจากธอร์นลิงมาที่ฮีโร่ และวงส้มล้อมฮีโร่ ฮีโร่ซ้อนอยู่บนปลายแถบ
- ธอร์นลิงสีเขียวบนพื้นหญ้าเขียวและอยู่ไกล ตัวเล็กราว 30 px
- ปุ่มสกิล 1 จางเพราะวงเตือนอยู่ใต้ปุ่ม
- ซุ้มหินปลายลานตัดกับท้องฟ้าจาง ผลึกฟ้าเขียวหน้าซุ้มกับขวามือเห็นชัด

**pool**
- บ่อ spring (วงหินมีแสงฟ้า) อยู่ใต้ฮีโร่ ปีกแสงม่วงโผล่ข้างตัว ฮีโร่บังบ่อเกือบหมด เห็นเฉพาะขอบหินและแสงฟ้า
- ปลายทางมีลานหินและผลึกฟ้า-ม่วงสูงตั้งเป็นแถว ผลึกสว่างกว่าพื้นหินมาก มืดน้อยกว่าสิ่งอื่นในฉาก
- ก้อนหินใหญ่ขวา (หญ้าบนหัวหิน) ใหญ่และสว่างพอ ๆ กับฮีโร่
- แถบ hp แสดง 100/120 ตัวเลข hp เล็ก (~10 px) อยู่บนแถบ

**boss-open**
- ฉากมืดกว่าทุ่งมาก (ค่าเฉลี่ย luma 0.32 เทียบ 0.64) พื้นหินสีน้ำเงินเทาเข้ม ลวดลายตารางหินชัดตลอดครึ่งล่าง
- บอสตัวเล็กอยู่บนกลางภาพ สีเข้มม่วง-น้ำเงิน หนามผลึกฟ้า-ม่วงสว่างกว่าตัว ชื่อบอสทองทับตัวบอสที่ระดับหัว (ชื่อทับบริเวณหนามผลึก)
- ผลึกใหญ่ซ้ายและขวาของบอสสว่างกว่าบอสเองในภาพขาวดำ
- แถบ hp บอสแดงชมพูเต็มความกว้างบนสุดของจอ ชื่อบอสซ้ำอีกครั้งบนแถบ
- ซ้ายบน: กล่องคำแนะนำเดิมของด่าน (ลากนิ้วเพื่อเดิน) ยังแสดงอยู่ในลานบอส
- ฮีโร่อยู่ระหว่างบอสกับขอบล่าง ขอบวงฟ้าเท้ายังอ่านชัดบนพื้นหิน

**boss-circle**
- วงเตือนกลมใหญ่ครอบบอสและกินพื้นแนวนอนเกือบ 360 px วงสีชมพูอมส้มโปร่ง (ไม่ใช่ส้มสด) ขอบวงบางเห็นชัดน้อยบนพื้นหิน วงในเล็กอยู่ใต้ตัวบอส
- ฮีโร่ยืนนอกวง ขอบวงด้านล่างอยู่เหนือหัวฮีโร่ ชื่อบอสทับวง

**boss-fan**
- วงเตือนทรงพัดกว้างครอบด้านล่างบอสและขยายถึงหัวฮีโร่ สีชมพูอมส้ม สีเดียวกับวงกลม ปลายพัดซ้ายขวาหายไปที่ขอบเฟรมบางส่วน (ขอบซ้าย x ~210, ขอบขวา x ~630)
- วงในตัวบอสเห็นเป็นวงชมพูเล็กใต้ตัว

**boss-dash**
- แถบพุ่งกว้าง (ราว 190 px ที่ระดับฮีโร่) เป็นสีแดงอมชมพูเข้มกว่าวงกลมและพัด ทอดจากบอสลงมาเกินขอบล่างของเฟรม
- ฮีโร่ยืนบนแถบ ปุ่มสกิล 2 จางเป็นเทาเพราะแถบอยู่ใต้ปุ่ม ปุ่ม 1 และ 3 ทึบ

**chars** (ครอป dpr 2)
- hero: ผู้เล่นหันหลัง หัวกลมเทาเงินมีเกล็ดสีขาวสะท้อนแสง ผ้าพันคอ teal ผ้าคลุมม่วง กางเกงน้ำเงินเข้ม ขอบตัวอ่านชัดบนพื้นดินสีเหลือง วงฟ้าเท้าสว่างกว่าตัว
- puffcap: หมวกชมพูจุดขาว ตัวครีมอ่อน หน้าเห็นตา สีหมวกตัดกับพื้นทางเบจชัด ตัวครีมเกือบกลืนกับสีทาง
- thornling: ตัวกลมเขียวสด หนามม่วง หน้าดุ สีเขียวตัดกับพื้นทางเบจชัด และกลืนกับหญ้าเขียวด้านข้างทาง
- prismback: เกราะหินเทา-ม่วง ผลึกฟ้า-ม่วงเป็นหนามบนหลัง ตาฟ้าสว่าง เล็บผลึกฟ้า silhouette ใหญ่ครอบเกือบทั้งกรอบครอป

**vfx**
- skill1 (ระฆัง): วงแหวนฟ้าและประกายทองรอบฮีโร่ ตัวเลขดาเมจเทาจางที่หัว ปุ่ม 1 ขึ้นตัวเลขคูลดาวน์ 8 ขอบปุ่มสว่าง
- skill2 (เสี้ยวจันทร์): เสี้ยวม่วงอ่อนโปร่งแสงเป็นประกายจุดชมพูม่วง ทั้งเสี้ยวบางและจาง ตัวเลขดาเมจเทาจางบนหัว puffcap ปุ่ม 2 แสดง 5
- skill3 (ผลึก): ผลึกเขียวฟ้าโปร่งแสงสูงข้างหน้าฮีโร่ บางส่วนมีประกายทอง ปุ่ม 3 แสดง 12 สีของผลึกใกล้สีหญ้าเขียวด้านหลัง
- hit-spark: เห็นวงเตือนส้มจางรอบฮีโร่ ส่วนประกายตีโดนมีขนาดเล็กมากบนตัว puffcap ที่ถูกฮีโร่บัง
- perfect-dodge: ข้อความ PERFECT จางบนยอดจอ ดาวทอง 3 ดวงบนพื้น ปุ่มหลบเรืองฟ้า puffcap ตัวหนึ่งใหญ่อยู่ล่างจอ ซ้อนกับฮีโร่ที่ขอบล่าง
- ult-locked: ไม่มีเอฟเฟกต์ มีแบนเนอร์ข้อความล็อกอย่างเดียว
