## 1. สาเหตุ (ข้อเท็จจริงจากโค้ดและ three.js r187)
1. **shader วงเตือนไม่แปลงสีออกจอ** `telegraphMaterial` เป็น `ShaderMaterial` ที่เขียน `gl_FragColor` ตรง ๆ โดยไม่มี `#include <colorspace_fragment>` แต่ `new Color(0xff7a1a)` เก็บค่าแบบ linear จึงออกจอเป็นประมาณ #FF3203 (ส้มกลายเป็นแดง) และ #FF0817 (แดง) ส้มกับแดงจึงแยกกันยาก (ยืนยันใน `node_modules/three/src/renderers/webgl/WebGLProgram.js`: ShaderMaterial ได้แค่ฟังก์ชัน `linearToOutputTexel` / `toneMapping` ไว้ใช้ แต่ไม่ถูกเรียกเอง)
2. **ขอบผสมสีขาว 70%** `mix(uColor, white, edge * 0.7)` (จากงาน "ขอบบางและสว่าง" ของ DES-003) ทำให้ขอบเป็นพีช/ชมพูอ่อน (~#FFBEA1 / #FFB1A8) ทั้งวงส้มและวงแดง
3. **ขอบโปร่งตามจังหวะกะพริบ** alpha ขอบ = 0.95 × pulse(0.5–1.0) = **0.475–0.95** ทำให้พื้นม่วงเข้มของลานหลังบรรยากาศ DES-004 ขั้น 1 ทะลุขึ้นมาได้ถึง 52% ภาพจึงออกชมพูหม่น
4. **วงในของท่ากวาด (CONE_INNER_R 1.2 ม.) ถูกวาดเป็น "ขอบ" ทึบทั้งแผ่น** นอกมุมกรวย `ang` ถูก clamp เป็น 0 ทำให้ `edge = 1` ได้แผ่นพีชทึบทับหน้าบอส (เห็นใน `crops/boss-fan-*-face.jpg` ฝั่ง before)
- **ไม่ใช่สาเหตุ:** fog (ShaderMaterial ค่าเริ่ม `fog: false`), tone mapping (ไม่มี chunk), แสง hemisphere (material ไม่รับแสง) ส่วนที่บรรยากาศทำคือพื้นใต้วงมืดและม่วงขึ้น จึงซ้ำเติมข้อ 2–3 ไม่ใช่ต้นเหตุ

## 2. สิ่งที่แก้ (เฉพาะ shader + 1 บรรทัดใน view.ts ส่วน telegraph) · draw calls +0 · pass +0
`src/render/fx.ts` `telegraphMaterial()`:
- ส่งออกด้วย `#include <colorspace_fragment>` และตั้ง `fog: false, toneMapped: false` ไว้ชัดเจน (ไม่รับแสง ไม่รับหมอก ไม่ tone map) **ขอบจึงออกจอเป็น hex เดิม #FF7A1A / #FF3355**
- ขอบใช้สี hex ล้วน (เลิกผสมขาว) และ alpha ขอบ 0.90–1.0 (จังหวะกะพริบ/ความถี่เดิม `8 + 22·prog`)
- วงในของท่ากวาดนอกมุมกรวยเป็น "พื้นในวง" (alpha 0.08/0.25 ตามการเติม) ไม่ใช่ขอบทึบ (พื้นที่โดนเท่าเดิม)
- `uBoss = (x, z, r)`: **เฉพาะเส้นขอบ** จางหายตรงพื้นใต้ตัวบอส (ระยะ < 1.9 ม., ไล่จาง 1.5→1.9 ม.) เพราะ depthTest ปิด เส้นที่อยู่ใต้ตัวบอสจึงถูกวาดพาดหน้าบอส ผู้เล่นยืนตรงนั้นไม่ได้ (sim ดันผู้เล่นออกถึง ≥ 1.9 + 0.42 = 2.32 ม. และบอสไม่มีสถานะ hop) การเติมพื้นและเส้นเวลาไม่ถูกจาง
`src/render/view.ts` ส่วน telegraph: ตั้ง `uBoss` จากตำแหน่ง render ของบอสทุกเฟรม (2 บรรทัด)
`src/render/atmosphere.ts`: ไม่ต้องแก้

**คงเดิม:** hitbox และรูปทรง (geometry/`makeTele` ไม่แตะ), เวลาเตือน, alpha พื้นในวง 0.08 → 0.25, ความกว้างแถบขอบ (smoothstep เดิมทุกค่า), การเติม/เส้นเวลา/ลูกศรท่าพุ่ง, hex, `renderOrder 10` + `depthTest: false` (วาดหลัง VFX ทุกชิ้นที่ renderOrder ≤ 5 และใต้ฮีโร่/วงเท้าฮีโร่ตาม ADR-005)
**ต้นทุน:** draw calls/triangles เท่าเดิมทุกภาพ (ตาราง 6) · ต่อพิกเซลของวงเตือนเพิ่ม 1 varying vec2, `distance` + `smoothstep` 1 ครั้ง และการแปลง sRGB (pow 3 ครั้ง) · ไม่มี texture/pass/render target เพิ่ม

## 3. วิธีวัด: ROI เฉพาะขอบวง (`tools/qa/tele-roi.mjs`)
```
npm run build                                    # หลัง
git checkout d9e6132 && npm run build && cp -r dist <dist-before> && git checkout -   # ก่อน
node tools/qa/tele-roi.mjs <out> --dist <dist>  --tag <before|after> --tiers low,medium,high --only circle,fan,dash,circle-vfx
node tools/qa/stage1-shots.mjs <out> --tag <tag> --only boss-circle,boss-fan,boss-dash          # ภาพมาตรฐาน + draw calls
```
- เฟรมเดียวกับ `stage1-shots.mjs` (seed 1, `start=boss`, ผู้เล่นหน้าบอส 6.7 ม., บังคับ `bossNext`, วงขึ้น +12 tick = tick 80, ความคืบหน้า slam 0.35 / sweep 0.46 / charge 0.32) · `circle-vfx` = เฟรม slam + กด Chime Burst แล้ว +14 tick ให้วง VFX ตัดขอบวงเตือน
- อ่านพิกเซลจาก WebGL ตรง (`gl.readPixels`, ไม่มี HUD) 5 ครั้งจาก state เดียวกัน: N ปกติ · N0 ซ่อนสิ่งที่วาดหลังวงเตือน (ฮีโร่ 13, วงเท้า 12, ดาวมึน 11) · H ซ่อนวงเตือน · H2 ซ่อนวงเตือน+VFX · M มาสก์ขอบ (shader สำหรับ QA ที่ใช้ `uShape/uCos/uInner/vUv` เดียวกันทุก build จึงวัด before/after ด้วยพิกเซลชุดเดียวกัน)
- **ROI** = พิกเซลที่จุดกึ่งกลางอยู่ในแกนทึบของแถบขอบ (วง/โค้ง d ≥ 0.97, ขอบข้างกรวย ang ≤ 0.01, ขอบข้างเส้นพุ่ง |x| ≥ 0.96, หัวท้ายเส้น) **ไม่รวมพื้นใต้ตัวบอส** และต้องมองเห็นจริง (N ≠ H และ N = N0) ดูภาพ `crops/roi-mask-844-medium.jpg` (สีเขียว = ROI)
- ค่าที่รายงาน: RGB เฉลี่ย, hue (circular mean), S/V (HSV), **ΔE00 (CIEDE2000)** และระยะ RGB ถึง hex เป้า, สัดส่วน ΔE00 < 10, luma ขาวดำของขอบเทียบสิ่งที่อยู่ใต้ขอบ, ความสดเทียบสีอุ่นอื่นทั้งในฉากและบนจอรวม HUD, กล่องหน้าบอส, draw calls ของเฟรมเกม (อ่านก่อน render ของ QA)
- ผลดิบ: `roi-before.json`, `roi-after.json`, `stage1-shots-before.json`, `stage1-shots-after.json`
