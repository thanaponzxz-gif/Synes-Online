## วิธีทำ (ทำซ้ำได้)
```bash
PY=/home/user/synes-online/tools/blender/.venv/bin/python        # Blender 5.3.0 (bpy)
SYNES_CHAR_VARIANT=r0 SYNES_KIT_OUT=/tmp/kit_r0.glb $PY tools/blender/build_kit.py   # "ก่อน" (r0)
$PY tools/blender/build_kit.py                                                         # A -> public/assets/models/synes_kit.glb
SYNES_CHAR_VARIANT=B SYNES_KIT_OUT=docs/qa/chars-v01/synes_kit_B.glb $PY tools/blender/build_kit.py
$PY tools/blender/verify_kit.py --rebuild-check                                        # A
SYNES_CHAR_VARIANT=B $PY tools/blender/verify_kit.py --rebuild-check --glb docs/qa/chars-v01/synes_kit_B.glb
$PY tools/blender/render_chars.py --glb "r0 (current)=/tmp/kit_r0.glb" --glb A=public/assets/models/synes_kit.glb \
    --glb B=docs/qa/chars-v01/synes_kit_B.glb --out docs/qa/chars-v01/sheet-chars.png
npm run build    # แล้วสลับไฟล์ dist/assets/models/synes_kit.glb ทีละแบบ (โค้ดชุดเดียวกัน) แล้วรัน
node tools/qa/stage1-shots.mjs <out>/<แบบ> --tag <แบบ> --only chars,boss-open,opening
node tools/qa/perf-field.mjs http://127.0.0.1:<port> <out> low,medium camp,boss,boss-flank,boss-behind   # dist ของแต่ละแบบ (tools/qa/serve.mjs)
```
- ช็อตในเกมใช้ build โค้ดเดียวกันและ URL GLB เดิม (`./assets/models/synes_kit.glb`) โดยสลับไฟล์ GLB ใน `dist/` ระหว่างรอบ ซึ่งให้ผลเท่ากับการฉีด `window.__SYNES_KIT_URL` แต่ไม่ต้องแก้ `tools/qa/`
