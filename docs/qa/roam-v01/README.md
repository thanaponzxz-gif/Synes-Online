# Free roam ขั้น 1 (roam-1) · 2026-11-27 · branch `lane/free-roam`

เปิดพื้นที่เดินอิสระทั้งทุ่ง + ชนสิ่งกีดขวาง + กล้อง (งานข้อ 4 ขั้น 1 ตามคำสั่งเจ้าของ 2026-11-27) · ฐาน `art/env-polish` `c33fa5b` (**ยังไม่มีหญ้าพริ้วไหว r4** เพราะ commit `d7ff5c5` ไม่อยู่บน remote และไม่ได้แนบ patch มา)

## ข้อเท็จจริง
- ruleset ใหม่ `roam-1` (ตัวเลขต่อสู้ = `combat-2`) เลือกด่าน `shared/data/roam.ts` · server replay ด้วย ruleset ที่บันทึกตอนเริ่ม · tuningHash ของ `roam-1` รวมข้อมูลด่าน · ruleset เดิมทุกตัว hash เท่าเดิม
- บน branch นี้เกมเปิดเป็น roam-1 เป็นค่าเริ่ม · `?roam=0` = ด่านทางเดินเดิม (`combat-2`)
- ทุ่ง = วงกลม 9 วงต่อกัน (~48 × 63 ม.) · สิ่งกีดขวาง 34 ชิ้น: ต้นไม้ 14, บ่อน้ำ 2 วง, หิน 4, เสาซาก 3, ของในค่าย/โคม 11 (ชนอย่างเดียว)
- ประตูลานบอส: ประตูผลึกย้ายไปปากทางเดินเข้าลานบอส (−2, −55.6) เปิดเมื่อฆ่ามอนลานกลางหมด (กติกาเดิม) · ประตูหน้าลานบอสเดิมไม่เปลี่ยน
- ขอบแผนที่: แนวต้นไม้ 2 แถวตามขอบ + หินผาด้านเหนือและสองข้างทางเข้าลานบอส (render เท่านั้น; การกั้นจริงคือขอบ walkable ใน sim)
- ทางดินเดิมยังวาดอยู่ เพื่อบอกทางไปบอส · ของประดับในทุ่งเหลือเฉพาะที่เดินทะลุได้ (ดอกไม้ พุ่มเล็ก คริสตัลเล็ก เห็ด) ของที่ดูแข็งทุกชิ้นชนได้จริง
- กล้อง: ใช้กล้องเดิม (ทิศคงที่มองไป −z) ตรวจแล้วที่ขอบใต้/ตะวันออก/เหนือ: ต้นไม้/หินที่บังผู้เล่นจางลงด้วยระบบ near-fade เดิม · ไม่ได้เปลี่ยนโค้ดกล้อง
- ด่านเดิม (`?roam=0`) ภาพไม่เปลี่ยน: ฉากนิ่ง (มุมบน, ค่าย, ขอบ 3 จุด) ต่างกัน 0 px · ฉากที่มีการตีต่างกันพอ ๆ กับรันซ้ำบิลด์เดียวกัน (กล้องสั่นใช้ `Math.random`)
