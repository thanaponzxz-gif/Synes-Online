## สวิตช์
- ไม่ใส่พารามิเตอร์ = ลุคใหม่ (ค่าเริ่ม)
- `?env=0` = ลุคเดิม**ทุกพิกเซล** (pixeldiff 22 ภาพ PNG ต่างกันเฉพาะใน HUD ที่มี CSS fade ตามเวลาจริง ได้แก่ปุ่มสกิล 1 และแถบ HP ค่าต่างสูงสุด 3/255 ในบางรอบ ส่วนฉาก 3D ตรงกัน 0 px · ผลอยู่ใน `env0-vs-before-pixeldiff.json` รันซ้ำแล้วตำแหน่งที่ต่างย้ายไปมา จึงเป็น noise ของ HUD)
- QA: `?wind=0` (ปิดหญ้าไหว) · `?envgrass=0` (ไม่มีหญ้า/ดอกไม้) · `?envdetail=0` (ไม่มี detail texture ของพื้น) · `?envfade=0` (ใช้ลาย fade 2×2 แบบเดิมแต่คงลุคใหม่ไว้)
- `?envlib=1` จะโหลด `public/assets/models/env_library_v01.glb` ถ้ามีไฟล์ (ตอนนี้ยังไม่มี จึงไม่ทำอะไร มีแค่ console.warn) ระบบจะค้นโหนดตามชื่อ: `tree_round`, `tree_pine`, `tree_round_b`, `rock_a`, `bush`, … ใช้แทนโหนดชื่อเดียวกันใน kit ส่วน `grass_tuft` และ `flower_small` ใช้เป็นแม่แบบหญ้า/ดอกไม้แทนแบบ procedural
