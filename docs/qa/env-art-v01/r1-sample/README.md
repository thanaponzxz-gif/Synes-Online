## สวิตช์
- ไม่ใส่พารามิเตอร์ = ลุคใหม่ (ค่าเริ่ม)
- `?env=0` = ลุคเดิม**ทุกพิกเซล** (pixeldiff 22 ภาพ PNG ต่างกันเฉพาะใน HUD ที่มี CSS fade ตามเวลาจริง ได้แก่ปุ่มสกิล 1 และแถบ HP ค่าต่างสูงสุด 3/255 ในบางรอบ ส่วนฉาก 3D ตรงกัน 0 px · ผลอยู่ใน `env0-vs-before-pixeldiff.json` รันซ้ำแล้วตำแหน่งที่ต่างย้ายไปมา จึงเป็น noise ของ HUD)
- QA: `?wind=0` (ปิดหญ้าไหว) · `?envgrass=0` (ไม่มีหญ้า/ดอกไม้) · `?envdetail=0` (ไม่มี detail texture ของพื้น) · `?envfade=0` (ใช้ลาย fade 2×2 แบบเดิมแต่คงลุคใหม่ไว้)
- `?envlib=1` จะโหลด `public/assets/models/env_library_v01.glb` ถ้ามีไฟล์ (ตอนนี้ยังไม่มี จึงไม่ทำอะไร มีแค่ console.warn) ระบบจะค้นโหนดตามชื่อ: `tree_round`, `tree_pine`, `tree_round_b`, `rock_a`, `bush`, … ใช้แทนโหนดชื่อเดียวกันใน kit ส่วน `grass_tuft` และ `flower_small` ใช้เป็นแม่แบบหญ้า/ดอกไม้แทนแบบ procedural

- **E1** ใช้สีพื้น 4 โทนต่อกลุ่ม (ผสมจาก grassA/B: `#D8EB8A`, `#2F8A63`, `#9C9A4E`, `#3D7468`) alpha 0.12–0.26 ขนาด 2–8 ม. และใช้ขีดใบหญ้าสว่าง/เข้มชี้ไปทาง −z (ขึ้นจอ)
- **E2** ขอบทาง: ขอบชื้นเข้ม 2 ชั้น (+1.45 ม./+0.75 ม.), ขอบ `pathEdge` +0.2 ม., พื้นทาง −0.22 ม., ขอบหยัก ±0.26–0.45 ม., ร่องล้อ ±0.75 ม. จาง 12%, กรวดสีเทาอุ่น
- **E3** เงาสัมผัสอบลง canvas แทน instanced decal (0 draw call, ความละเอียด ~7.5 px/ม. ใน medium และ ~3.7 ใน low จึงนุ่มมาก) ใช้สี `#1F3F48` (เย็น) และแกน `#1B3326` · ปิดใน high ที่มีเงาจริง
- **E4** กอหญ้า 3 ใบ สูง 0.08–0.13 ม. ในทางเดิน / 0.12–0.20 ม. ที่ขอบ / 0.16–0.28 ม. ในทุ่ง ใช้ normal ชี้ขึ้นทั้งสองด้านเพื่อให้รับแสงเหมือนพื้น (ไม่เป็นหนามดำ) ลมไหว ±4.5 ซม. ที่ปลาย
- **E5** ดอกไม้ 4 สี: violet `#A78BFA`, blossom `#FF9EC7`, ขาว `#F7F3FF`, lumen อ่อน `#8FE9F0` **ไม่ใช้ทอง/ส้ม/แดง** (ส้ม/แดงสงวนไว้ให้วงเตือน ส่วนทองตัดออกเพื่อไม่ให้แย่งกับวงเตือน) กลีบเอียง ~50° เข้าหากล้อง ไม่มีดอกไม้ในทางเดิน (ระยะ < 0.15 ม. จากขอบ)
- **E6** โทนแสง: แดด `#FFE7C2` ×2.45, ฟ้า `#D3E6FF` ×1.5, พื้น hemi `#7EAE66`, ทิศแดด (11,17,2) (เงาตกไปทางซ้ายและห่างกล้องเล็กน้อย) ใช้เฉพาะโทน `dewlight`
- **E7** สีต่อ instance: ต้นไม้ค่า 0.86–1.06 แบ่ง 3 กลุ่มคือ มะกอก (×1.06, 1.0, 0.84) / เย็น (×0.9, 0.97, 1.05) / กลาง · หินอุ่นขึ้นเล็กน้อย
- **E8** เพิ่มหิน (~12%) และพุ่มไม้ (~18%) ในระยะ 1.2–9 ม. จากทาง + หินเล็ก 0.2–0.4 ที่ขอบทาง ใช้ random stream แยก **ต้นไม้/หินเดิมทุกชิ้นอยู่ที่เดิม** ไม่วางหญ้า/ของใหม่ในรัศมี 1.4 ม. รอบคริสตัลนำทาง และในรัศมี arena.r+3
- **E9** (ข้อสังเกต 5) ของริมจอไม่ถูกจาง ทำให้ต้นไม้ใกล้กล้องที่ริมจอทึบและใหญ่ขึ้น (เช่น ต้นซ้ายที่ทับจอยใน pathA-low และต้นขวาใน pathA-medium) **เรื่องนี้เป็นการตัดสินใจด้านดีไซน์ (สิ่งที่บังฉาก) ต้องให้ทีม A ตัดสิน** ทางเลือกคือ `?envfade=0`

## สิ่งที่ยังอ่อน
- ภายในลานแรก (plaza) ยังเป็นดินเรียบผืนใหญ่ เพราะมีแค่ detail + รอยด่างจาง ๆ ควรเพิ่มลายหินปูหรือวงหญ้าตรงกลาง (ต้องให้ทีม A ออกแบบ)
- ที่ 844 px หญ้าเล็กและจางจนอาจอ่านเป็น "noise" มากกว่าเป็นกอ ส่วนที่ 1672 อ่านได้ดีกว่า
- เงาสัมผัสนุ่มมากจนไม่เห็นชัดในมุมกล้องต่ำ (เงาเยื้องไปด้านหลังต้นไม้) ส่วน low tier เบลอยิ่งกว่า
- ต้นไม้ยังเป็นทรงเดียวกันหมด (kit เดิม) รอ `env_library_v01.glb` ซึ่ง hook รองรับแล้ว
- ต้นไม้ทึบริมจอ (E9) กินพื้นที่ใต้ปุ่ม HUD มากขึ้น
- pc/medium FPS −8% ใกล้เพดานงบ ถ้าต้องการส่วนเผื่อ ให้ปิด detail ใน medium (`?envdetail=0` ≈ +1.5 FPS)
- ตัวเลขทั้งหมดมาจาก SwiftShader **ยังไม่ได้ทดสอบบน Android/iPhone จริง**
