## Golden Reference (2026-11-23): `exp/env-sample-a` r3 `212c989` → merge เข้า `art/env-polish`
ตรวจอิสระ 3 รอบ (agent ตรวจแยกจากผู้ผลิต ถ่ายภาพจากเกมเอง): r1 ผ่านแบบต้องแก้ → r2 ผ่านแบบต้องแก้ → **r3 ผ่าน**
คะแนน r3 (1–5): พื้น 4 · ทางเดิน 4 · เงา 3.5 · ฉากกลาง 4 · ความลึกต้นไม้ 3.5 · ของใกล้กล้อง 4 · อ่านเกม 4 · low tier 3.5
**กฎของ Golden Reference เมื่อขยายไปส่วนอื่นของด่านแรก:**
1. พื้น: กลุ่มสีหญ้าหลายโทน + ขีดใบหญ้า · ทาง: ขอบหยัก ขอบชื้นเข้ม กรวด หญ้าลามเข้า
2. กอหญ้า/ดอกไม้: mesh เดียว (+1 draw call) เป็นกลุ่ม 2–5 กอ เตี้ยบนทางเดิน · ดอก violet / blossom / ขาว / lumen อ่อน · ห้ามส้ม/แดง
3. เงาต้นไม้: อบลงพื้นเฉพาะวงเล็กที่โคนต้น (ไม่ทิ้งหลุมดำเมื่อต้นไม้จาง)
4. ห้ามวางของใหม่ที่กล้องเห็นว่าอยู่หลังจอย/ปุ่ม · ของใกล้กล้องที่ทับโซน HUD หรือกินจอเกิน 12% จางแบบลายจุดละเอียด
5. ไม่วาดหญ้าตอนสู้บอส (ฉากบอสต้องเท่า `?env=0`) · สร้างทุกอย่างก่อนเฟรมแรก
6. งบ 844×390: draw calls medium ≤ 60, low ≤ 56 · FPS headless ไม่แย่กว่า −10%
**ตัวเลข r3:** draw calls ทุ่ง +1–2 (สูงสุด 55 medium / 53 low) · tris ทุ่ง low +6.6k, medium +14.5k · ฉากบอสเท่าเดิม · heap +1.3 MB · transfer +8 KB
**เวลาโหลด:** ผู้ตรวจวัด android-low 5 คู่สลับ ได้ median −11 ms (noise ±400 ms) ผู้ผลิตวัด 6 รอบได้ +287 ms → **headless แยกความต่างระดับ 250 ms ไม่ได้ ต้องวัดบน Android จริงก่อนขึ้น Pages**
**ยังอ่อน:** ลานแรกยังเป็นดินเรียบ · ทรงต้นไม้ยังซ้ำ (รอ env_library) · โซน HUD เป็นค่าคงที่ ไม่ครอบคลุมตอนกล้องถอย · ต้นไม้ติดพื้นน้อยกว่า r2 เล็กน้อย
