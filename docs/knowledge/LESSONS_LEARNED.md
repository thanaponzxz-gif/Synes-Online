# Lessons Learned: Synes Online

> บทเรียนที่ agent ทุกตัวควรรู้ก่อนเริ่มงาน เขียนสั้น 1–3 บรรทัดต่อข้อ พร้อมหลักฐาน (commit/ไฟล์)
> **อ่านเฉพาะหมวดที่เกี่ยวกับงานรอบนี้** · เพิ่มข้อใหม่ท้ายหมวด ใช้เลขถัดไป · ห้ามลบข้อเก่า ถ้าล้าสมัยให้ขีดฆ่าแล้วบอกข้อที่มาแทน
> รูปแบบ: **L-NNN** (วันที่) บทเรียน — หลักฐาน

## A. Gameplay / sim
- **L-001** (2026-11-20) กำหนดเวลาในเกมเป็นจำนวน tick ไม่ใช่วินาที ค่า 0.87 s ใน sim จริงกลายเป็น 27 tick ไม่ใช่ 26 ตามที่ดีไซน์ต้องการ — `c3a52f2`
- **L-007** (2026-11-20) บอททดสอบความถูกต้องได้ แต่ตัดสินเรื่อง "ความรู้สึก" ไม่ได้ (คูลดาวน์หลบ 17/26 tick บอทชนะ 100% ทั้งคู่) ต้องให้คนเล่นจริง — `docs/qa/dodge-cd-compare.md`

## B. QA / เพลย์เทสต์
- **L-008** (2026-11-20) ก่อนสรุปว่าเกมไม่ยุติธรรม ให้ตรวจชุดทดสอบก่อน ชุดทดสอบเคยส่งปุ่มช้า 0.57–1.07 s และเล่น replay จาก seed + input log ทุกครั้ง — `3389f98`
- **L-012** (2026-11-20) รายงานของ agent เป็นข้อมูล ต้องตรวจซ้ำ "การโดนที่ดูไม่ยุติธรรม" 2 ครั้งในรอบ 3 เล่นซ้ำแล้วพบว่าโดนจริง — `docs/qa/playtest-agent-round3.md`
- **L-013** (2026-11-20) container คลาวด์เปิด `github.io` และหน้า claude.ai ที่ต้องล็อกอินไม่ได้ จึงยืนยันหน้าเว็บที่โฮสต์แล้วเองไม่ได้ ต้องให้เจ้าของเปิดบนเครื่องจริง — `docs/HANDOFF.md` (GitHub Pages)
- **L-018** (2026-11-20) ตัวเลข perf ทั้งหมดมาจาก Chromium + GPU ซอฟต์แวร์ ห้ามรายงานเป็นตัวเลขของมือถือจริง — `docs/qa/baseline-2b.md`

## C. Asset / ภาพ
- **L-009** (2026-11-20) repo เป็น Public ห้ามเก็บภาพอ้างอิงจากเกมอื่นใน repo ให้บันทึกเป็นตารางฟังก์ชันแทน — `docs/design/REQ-001-skills-auto.md`
- **L-010** (2026-11-20) บันทึก prompt ฉบับเต็มและบัญชีที่ใช้**ตอนสร้างภาพ** HUD skin v01 เข้าเกมแล้วแต่ prompt ยัง "ไม่ทราบ" — `docs/ASSETS.md`
- **L-011** (2026-11-20) ภาพโปร่งใสจาก AI มีจุดรบกวน alpha ต่ำ (1–15) ทั่วแผ่น ต้องให้สคริปต์ตัดภาพลบและตรวจขอบทุกครั้ง — `tools/art/slice_hud.py`
- **L-006** (2026-11-19) โฮสต์ Artifact ของ claude.ai ไม่รับ `.glb` build สำหรับ Artifact จึงใช้ glTF JSON ฝังข้อมูล — `docs/HANDOFF.md` รอบ 1
- **L-015** (2026-11-20) กฎกลางของเจ้าของเขียนโดยมี Godot เป็นฐาน (มาจาก TERRAVIA) ต้องแปลงให้ตรงกับ Synes ทุกครั้ง (Three.js) โดยไม่เปลี่ยนเอนจิน — มติ ข-1, ADR-006

## D. Workflow / Claude Code / token
- **L-002** (2026-11-20) worktree ของ agent อยู่ใน `.claude/worktrees/` vitest เคยเก็บเทสต์ซ้ำจากที่นั่น ต้อง exclude ไว้เสมอ — `11df2a5`, `vite.config.ts`
- **L-003** (2026-11-20) เซสชันที่เริ่มนอกโฟลเดอร์ repo (เช่น `/home/user`) ไม่อ่าน `.claude/settings.json` ทำให้ `autoCompactWindow` ไม่ทำงาน ให้เริ่มเซสชันจากโฟลเดอร์ repo (สาเหตุยังไม่ยืนยัน) — `docs/HANDOFF.md` rollover 2-B
- **L-004** (2026-11-20) ไฟล์แนบจากเจ้าของบางครั้งไม่เข้ามาในเซสชัน (DES-001) ให้ตรวจโฟลเดอร์อัปโหลด, repo และ Drive ก่อน ถ้าไม่มีให้ขอให้ commit บน branch `design/*` หรือวางเป็นข้อความ — `docs/HANDOFF.md`
- **L-014** (2026-11-20) การแยกเซสชัน/agent ไม่ได้เพิ่มโควตา token ได้แค่บริบทแยกและทำขนาน — PROJECT_SYNES ข้อ 1, code.claude.com/docs/en/costs
- **L-016** (2026-11-21) พฤติกรรมเครื่องมือเปลี่ยนตามเวอร์ชัน: Explore subagent ใช้ Haiku มาก่อน แต่ตั้งแต่ Claude Code v2.1.198 ใช้โมเดลเดียวกับเซสชันหลัก ให้บันทึกเวอร์ชันทุกครั้งที่อ้างพฤติกรรมเครื่องมือ — code.claude.com/docs/en/sub-agents
