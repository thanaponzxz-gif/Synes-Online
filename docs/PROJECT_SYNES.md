# โปรเจค Synes: ความจำหลักของโปรเจค

> ไฟล์นี้คือ "ไอเดียสำคัญที่ต้องรักษาไว้" ทุกเซสชันโหลดผ่าน CLAUDE.md อัตโนมัติ
> แก้ได้เฉพาะตอนที่มีการตัดสินใจใหม่หรือสถานะเปลี่ยน และให้เขียนสั้น ๆ เป็นข้อเท็จจริง รายละเอียดเต็มให้ลิงก์ไปที่ docs อื่น

## 1. เป้าหมายและสิ่งที่ห้ามเปลี่ยน (จากบรีฟของเจ้าของ)
- เกมแฟนตาซีออนไลน์ 3D ที่กดลิงก์แล้วเล่นบนเบราว์เซอร์มือถือได้ทันที โดยไม่ต้องติดตั้งแอปหรือสมัครบัญชีก่อนเล่นเดโม
- **แยกจาก TERRAVIA โดยเด็ดขาด** ห้ามเปลี่ยนชื่อ ห้ามย้ายโค้ด และห้ามแก้ repo ของ TERRAVIA
- โลก ตัวละคร ศัตรู ภาพ เสียง และ UI ต้องเป็นต้นฉบับ ใช้เกมอื่นเป็นแรงบันดาลใจได้เฉพาะด้านความรู้สึก
- ทำ vertical slice ให้เล่นสนุกก่อน แล้วค่อยขยาย **ห้ามสร้างระบบ MMORPG ทั้งหมดล่วงหน้า**
- client ห้ามตัดสินผลต่อสู้หรือรางวัลเอง (ดู ADR-002)
- ออกแบบแนวนอนก่อน ปุ่มต้องไม่บังตัวละคร ศัตรู หรือวงเตือน
- รายงานต้องแยกข้อเท็จจริง ข้อเสนอ และสิ่งที่ยังไม่ทราบ ถ้าไม่ได้ทดสอบบนอุปกรณ์จริงต้องเขียนว่า "ยังไม่ได้ทดสอบ"
- asset ทุกชิ้นต้องลงทะเบียนใน `docs/ASSETS.md` และต้องตรวจโค้ดของ plugin ก่อนใช้งาน
- **การแยกเซสชันคือการแยกบริบทงาน ไม่ใช่การได้โควตาโทเคนเพิ่ม** ห้ามกล่าวอ้างแบบนั้น
- ถ้าแพลตฟอร์มบังคับให้เจ้าของยืนยัน ต้องรอเจ้าของเท่านั้น การที่เจ้าของไม่ตอบไม่ถือเป็นการยืนยัน

## 2. ตัวตนของเกม
- โลก **Synes** คือดินแดนที่แสงมีเสียง เรียกว่า "ลูเมน" ไหลผ่านคริสตัล *ซายน์* สิ่งสำคัญทุกอย่างจึงสื่อด้วย สี + รูปทรง + เสียง
- ผู้เล่นคือ Wayfarer ที่มีผ้าพันคอสี teal ถือดาบ Chime Blade ศัตรูคือพัฟแคป, ธอร์นลิง และบอสปริซึมแบ็ก
- palette: lumen #5CF2E6 · violet #A78BFA · blossom #FF9EC7 · gold #FFC857 · teal #2BB3A3
- **สีส้ม #FF7A1A และแดง #FF3355 สงวนไว้สำหรับวงเตือนการโจมตีเท่านั้น**
- หัวใจของการต่อสู้คือ อ่านท่า → หลบ/หลบเพอร์เฟกต์ → ตีสวนในช่วงที่ศัตรูเสียหลัก (✦) → ใช้ฉาก (ล่อบอสชนเสา)

## 3. การตัดสินใจที่ล็อกแล้ว (รายละเอียดใน `docs/DECISIONS.md`)
| ADR | เรื่อง | สรุป |
|---|---|---|
| 001 | เอนจิน | Three.js (ชนะ PlayCanvas ทั้งขนาดและเวลาโหลดใน spike) **รอยืนยันบนเครื่องจริง** และเปลี่ยนได้เพราะเอนจินอยู่แค่ใน `src/render/` |
| 002 | ความถูกต้องของผล | sim แบบ deterministic 30 Hz ใน `shared/` (ไม่ใช้ trig/random) server จำลองซ้ำจาก input log แล้วตัดสินผลและรางวัล |
| 003 | asset | ใช้โมเดลต้นฉบับจากสคริปต์ Blender (`tools/blender/build_kit.py`) และเสียงสังเคราะห์ ไม่มี asset ภายนอก |
| 004 | ลิงก์ทดลองเล่น | ตอนนี้ใช้ claude.ai Artifact (โหมดออฟไลน์) เป้าหมายคือ static CDN + Node server |
| 005 | ชั้นความชัด | วงเตือนวาดทับทุกอย่าง, บอส/เสา/ประตูที่บังผู้เล่นจางลง, phase 2 มีจังหวะ 2 ท่า → ฝนผลึก → พุ่งชน, คำแนะนำขึ้นเมื่อสิ่งที่พูดถึงอยู่บนจอ |
| 006 | Hybrid Asset Pipeline v1 | งานศิลป์ใหม่ต้องผ่านใบสั่งงาน → inbox → ตรวจ → เจ้าของอนุมัติ (`docs/ASSET_PIPELINE.md`) มติ: ใช้ Three.js ต่อ, โมเดลจากสคริปต์ Blender นับเป็นงาน Blender ต้องมีภาพเทียบในเกมให้อนุมัติ, คงสิทธิ์ push |
