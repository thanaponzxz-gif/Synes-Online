### 2.3 สเปก (จากกล่อง dispatch 5.2 ไม่เปลี่ยน + ข้อกำหนดความทนทานที่เป็นงานวิศวกรรม)
- CLI: `node tools/qa/make-patch.mjs <base> <out.patch> [paths...]` · พิมพ์ SHA256 (ตัวพิมพ์ใหญ่ 64 หลัก) และจำนวนไฟล์ใน patch · exit ≠ 0 เมื่อผิดพลาด
- เรียก git ด้วย `execFileSync('git', [...args])` แบบ argument array เท่านั้น (ห้าม `shell: true`, ห้ามต่อ string เป็นคำสั่ง)
- index ชั่วคราว: `GIT_INDEX_FILE` = ไฟล์ใน `os.tmpdir()` (`mkdtemp`) → `git read-tree <base>` → `git add -N -- <paths>` → `git diff --binary --output=<out> <base> -- <paths>` → ลบไฟล์/โฟลเดอร์ชั่วคราวใน `finally` (ทั้งกรณีสำเร็จและ error)
- ไม่ใส่ paths = ทุกไฟล์ที่ต่างจาก base รวมไฟล์ใหม่ที่ไม่ถูก ignore (`git ls-files --others --exclude-standard` + `git diff --name-only <base>` บน index ชั่วคราว)
- เขียนไฟล์ด้วย git (`--output`) เท่านั้น ไม่ผ่าน stdout/redirect · ไม่แปลง EOL
- **ความทนทานต่อ config ของผู้ใช้ (ข้อเพิ่มจาก PM, งานวิศวกรรม):** ส่ง `-c` ทับค่าที่เปลี่ยนรูปแบบ diff: `core.autocrlf=false`, `core.safecrlf=false`, `diff.noprefix=false`, `diff.mnemonicPrefix=false`, `diff.relative=false`, `color.ui=false` และใส่ `--no-color --no-ext-diff --no-textconv` · ค่า `diff.renames` ให้คงค่าเริ่มของ git (ห้ามเดา) แล้วรายงานถ้า AC-1 ไม่ตรง
- base ต้องเป็น commit ที่มีอยู่ (`git rev-parse --verify <base>^{commit}`) · `<out>` ต้องอยู่นอก path ที่ถูก diff
