- **ขั้นตอน:**
  1. ยืนยัน flag จาก README ทางการของ gltfpack ก่อนรัน (โดยเฉพาะการคงชื่อ node/mesh/material เพราะเกมหาชิ้นจากชื่อ node และการปิด quantization)
  2. วัดฐาน: ขนาดไฟล์ดิบ + gzip + brotli ของ GLB ทั้งสอง, เวลา parse ใน headless (`tools/qa/bench.mjs`)
  3. สร้าง 2 แบบ: (ก) บีบอัดอย่างเดียว ไม่ quantize (ข) quantize + บีบอัด · ไฟล์ทดลองตั้งชื่อตามกฎ `ประเภท_ชื่อ_vNN`
  4. แก้ `models.ts` บน `exp/meshopt`: ตั้ง `setMeshoptDecoder` ให้ loader ทั้ง 3 จุด (ไม่เปลี่ยนอย่างอื่น)
  5. ปรับ `glb-check` บน exp ให้รับ `EXT/KHR_meshopt_compression` และตรวจว่าชื่อ node/tris/material เท่าไฟล์เดิมทุกตัว

- **ถ้า pixel-diff ≠ 0** (เช่นแบบ ข ที่ quantize normal) → หยุด ส่งภาพเทียบให้ทีม A ตัดสิน ห้ามเลือกเอง
- **ก่อนใช้จริง:** เจ้าของเปิดบน iPhone (ตัวถอดใช้ WebAssembly) · แก้ `ASSET_CONTRACT.md`/`verify_kit.py`/`glb-check` ที่ตอนนี้ห้ามบีบอัด · ลงทะเบียนเครื่องมือ
