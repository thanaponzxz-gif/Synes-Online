## 2. ลำดับงาน
1. **(ทำแล้วในเซสชันนี้)** แก้ 3 เรื่องที่ตรวจซ้ำแล้วจากเพลย์เทสต์รอบ 3 (ดู HANDOFF)
2. **(Sonnet, ไม่ต้องรออนุมัติ)** "หลบเร็วไป": ถ้าวงทำงานขณะผู้เล่นหลบไปแล้วแต่ยังไม่พ้นวง ให้ขึ้นคำว่า "หลบเร็วไป" หรือ "ยังไม่พ้นวง" สั้น ๆ ที่ตัวผู้เล่น
   ผู้ทดสอบรอบ 3 สับสนเรื่องนี้ 2 ครั้ง (step 61, 77)
3. **(Sonnet)** นำส่วนราคาถูกของต้นแบบเข้า `main` แบบปิดไว้ (`?style=1` เปิด, ค่าเริ่มต้นปิด) **ไม่เอาเส้นขอบแบบ inverted hull**
   ทำภาพเทียบก่อน/หลัง 3 จุด (ทาง, ลานต่อสู้, ลานบอส) และวัด bench tier low/medium
4. **(Opus เขียน → เจ้าของอนุมัติ → Sonnet/Blender ผลิต)** ใบสั่งงาน 3 ใบใน `docs/handoff/` (สถานะ DRAFT)
5. หลังเจ้าของอนุมัติ: ผลิตตามใบสั่งงาน → ภาพเทียบในเกม → เจ้าของอนุมัติ → เปิดเป็นค่าเริ่มต้น
6. ปิดรอบ: เพลย์เทสต์ agent รอบ 4 + bench (เป้าหมาย: draw calls ไม่เกินเดิม +5, FPS ลดไม่เกิน 5%, คะแนนภาพ ≥ 8)
